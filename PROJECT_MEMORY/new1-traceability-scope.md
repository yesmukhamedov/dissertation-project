Checked on disk rather than taken from the flag. NEW-1 is **not** "the numbers are
unsourced" — it is narrower and sharper than that.

## The chain is intact up to `VALUES.md`

Every signature value the dissertation states was traced to `VALUES.md` (repo root)
and found: the four Config wF1 values and all six Exp-1 pairwise differences, the
CLAHE optimum (2.5, 0.03) and the flat-field σ, both generalization ratios
(0.8976 / 0.8577), the ALO effect bounds, H-7's +0.0689 / +0.0541 with the 0.0041
margin, Exp-6's four spread figures, E-7's three differences, and the H-3
distance-reduction bounds. **Nothing in the text is unsourced.**

## What is missing is the chain *behind* `VALUES.md`

A hand-transported summary is not a primary output file, and
`experiments/outputs/` holds a **different, earlier run** (July; latest files
2026-07-30). The disagreement is not rounding:

- `exp5/clinical_degradation_results.json` records `h7_supported: false` and puts
  IDRiD at wF1 **0.5388 integrated against 0.6154 baseline** — the **opposite sign**
  to the +0.0689 the dissertation reports. Messidor-2 there is +0.0139, not +0.0541.
- `exp2/ablation_summary.json` carries a **three-fold** baseline of 0.7611 where the
  text has a five-fold L0 of **0.7538**.

The H-7 specification changed between the two runs (Δ_drop → absolute wF1), so this
is **not evidence against the current result** — but it is exactly why the old
artifacts can never serve as the corroboration NEW-1 asks for. Do not "cross-check"
the thesis against them; `results/INTEGRITY_NOTE.md` sets that standing rule.

**To close NEW-1 the candidate must produce the 2026-08-03 run-2 artifacts from
wherever that run executed.** Nothing inside this repository closes it. See
[[results-knowledge-base]].
