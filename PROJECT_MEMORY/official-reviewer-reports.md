## Инструмент для чтения сканов

падает. Рабочий обход: вытащить встроенный JPEG страницы через `pypdf` + Pillow и читать PNG
(скрипты остались в скретчпаде сессии). Бледные сканы (Тоқтарова) читаются только после
`ImageOps.autocontrast(cutoff=(0.5, 30))` + `ImageEnhance.Contrast(2.6)`.
