**Открыто 2026-09-03.** Кандидат поставил задачу «получить патент на demo с КазПатент».
Патент на веб-приложение в РК невозможен — программы для ЭВМ исключены из патентоспособных
объектов. Правильный (и общепринятый в корпусе диссертаций) документ — **свидетельство о
внесении сведений в Государственный реестр прав на объекты, охраняемые авторским правом**,
выдаёт РГП «НИИС» МЮ РК (kazpatent.kz / qazpatent.kz).

Это закрывает пробел, зафиксированный в [[peer-appendix-norms]] (авторское свидетельство —
у 6 из 10 соседей по корпусу, самый частый некодовый тип приложения) и в
[[official-reviewer-reports]] («свидетельства НЕТ», подтверждено 2026-08-13 — **эта запись
станет неверной после получения**). Пустое поле — `council/METADATA.toml`,
`copyright_certificate = ""`.

## Условия услуги (сверено 2026-09-03, тарифы меняются)

- Портал подачи: **https://newcab.kazpatent.kz**, подпись **ЭЦП**
- Оплата **3 МРП = 12 975 ₸** (МРП 2026 — 4 325 ₸); льготным категориям — 5 % от 3 МРП
- Срок — сведения вносятся в Реестр в течение **1 рабочего дня** со дня поступления
  заявления; свидетельство в электронной либо бумажной форме
- Реферат для программы для ЭВМ обязан включать: название, ФИО автора, дату создания,
  область применения, назначение, функциональные возможности, исходный код, основные
  технические характеристики, язык программирования, тип реализующей ЭВМ

## Пакет — `ip/kazpatent/`

`README.md` (процедура и порядок действий), `referat.md` (реферат по п. 1–10 Правил),
`zayavlenie.md` (данные для полей заявления + чек-лист), `make_listing.py` (генератор
листинга исходного текста), `make_pdf.py` (вёрстка обоих документов в PDF).
`ip/kazpatent/build/` — генерируемое, в `.gitignore`.

**Подаём два PDF: `filled/referat.pdf` (4 стр.) и `build/listing_core.pdf` (135 стр.).**
Сборка — строго в этом порядке, иначе реферат назовёт неверное число страниц листинга:
`make_pdf.py --only listing` → `filled/fill.py` → `make_pdf.py --only referat`. Листинг
оставляет счётчик страниц в `build/listing_core.pages`, оттуда его берёт `fill.py`.
Шрифты — Times New Roman 12 пт и Consolas 8 пт из `C:/Windows/Fonts`: **встроенные шрифты
PDF кириллицы не содержат**, Courier нарисовал бы чёрные квадраты. Оценку «~N страниц из
расчёта 50 строк на страницу» из шапки листинга убрали — она противоречила реальной
вёрстке (135 стр. против 202).

Объёмы листинга на 2026-09-03: полный — **34 929 строк / 136 файлов ≈ 699 стр.**; основные
модули (`--core`: preprocessing, models, training, explainability, demo/server/app) —
**10 076 строк / 48 файлов ≈ 202 стр.**; сокращённая редакция «первые 25 + последние 25
страниц» — на случай, если в НИИС попросят урезать. **Подаём `--core`.**

**Заполненные документы — `ip/kazpatent/filled/`, каталог в `.gitignore`** (там ИИН, домашний
адрес и телефон, а репозиторий ездит между тремя машинами). В git — только шаблоны.
`ip/kazpatent/certificate/` тоже игнорируется.

### Грабли портала (проверены на собственной шкуре, не переоткрывать)

1. Тип участника после создания заявки не меняется; берётся из профиля кабинета.
2. Своего участника из роли не удалить.
3. Двух участников с одним ИИН и одной ролью портал не допускает.
4. **Поле «Исходный код» принимает только zip/rar**, PDF напрямую не грузится. В архив
   класть **только заявленный файл** — готовый `build/listing_core.zip` (внутри один
   `listing_core.pdf`). Архив со всеми листингами сразу (full + core + 25+25) — повод для
   запроса эксперта.
5. **Реферат подаётся не файлом, а шестью полями** форматированного текста: область
   применения (п. 4), назначение (п. 5), функциональные возможности (п. 6), технические
   характеристики (п. 8), языки программирования (п. 9), тип ЭВМ (п. 10). Скрепка для файла
   реферата появляется позже и опциональна.
6. Поле даты — с маской: вводить `03092026`, точки ломают значение.
7. Выпадающие списки не фильтруются, Enter выбирает первый пункт (так однажды выставилась
   Австралия) — выбирать мышью.
8. Казахстан называется **«Республика Казахстан»**, сортируется на «Р».
9. Region для Наурызбайского района — **город Алматы**, не «Алматинская область».
10. После «Оплатить подачу заявки» заявка уходит в просмотр; правки — через **Edit**.
