## Заявленные ограничения текущей редакции

- H-7 заявляет **внешнюю производительность, а не устойчивость**: 2/2 по рабочей форме
  (+0.0689 IDRiD, +0.0541 Messidor-2), но запас Messidor-2 над MCID = 0.0041, а CI⁻ (+0.0362)
  ниже порога — по форме S это законно, но «комфортным» проход называть нельзя. **Нельзя
  утверждать снижение деградации**: относительно арки падают почти одинаково (21.2%/19.1% на
  IDRiD, 16.7%/16.7% на Messidor-2). Отозванная форма Δ_drop сама по себе вклад в §5.4:
  `Δ_drop(D) − Δ_drop(C) ≡ 0.0655 − Δ wF1(X)` — метрика требует бить baseline сильнее на чужих
  данных, чем на своих, и штрафует арку за её же in-domain-выигрыш. **Тот же дефект — у g_ratio
  в H-6** (падает в 2 группах из 5 при росте абсолютного wF1 во всех пяти); один аргумент
  закрывает обе метрики.
- PC-8: все 7 вкладов значимы, и иерархия **разрешается** — фотометрические стадии впереди
  (41% прироста). Разрешается именно **группировка**, а не строгий порядок 1–7: соседние ранги
  внутри шума.
- Пороги H-4/H-6 берут обе арки → различие даёт сравнение с baseline и сокращение разброса
  (std wF1 −2.4×, std AUC −3.1×).
- Stage 3 (FOV-маска) не изолирована в аблации (L3 = Stage 2+3 совместно) — остаток G-8.
- exp3/5/6 считаны с чекпойнтов fold 0 — межфолдовой дисперсии нет.
- G-3: клинические (KZ) Grad-CAM overlay не сделаны — единственный незакрытый пробел по H-5.

## Durable-операционные факты (не зависят от прогона)

- **GPU доступен ЛОКАЛЬНО через WSL.** Рабочая машина = GPU-бокс: в WSL Ubuntu `nvidia-smi` видит
  RTX 3060, окружение `dr-classifier`
  (`/home/yesmu/miniconda3/envs/dr-classifier/bin/python`) = torch **2.5.1+cu121, cuda True**.
  Из WSL пути `/mnt/d/phd/...`. Системный `C:\Python312` = **torch cpu-only** → для GPU звать WSL.
  Долгий WSL-джоб — через Bash `run_in_background` с foreground-вызовом `wsl`.
- **Гейт eval для EffNet:** `mixed_precision: false` (AMP роняет EffNet cuDNN).
- **exp4/IDRiD:** маски лежат в «A. Segmentation», а не в «B. Disease Grading»; пересечение
  с масками = **54 изображения**. Сэмплировать из grading-сплита — ошибка (даёт n=5).
- **Инструменты добивки exp2:** `run_exp2_partA.py --fold-list N` добивает отдельный фолд
  (пишет `ablation_partial_foldsN.json`, не трогая канон); `scripts/rebuild_exp2_summary.py`
  пересобирает канонический summary из `metrics.csv` (+`--recompute-quality`).
- **A7 (compute) закрыт:** `experiments/scripts/benchmark_compute.py` (FLOPs через штатный
  `torch.utils.flop_counter`) → 4-й канал стоит +0.9% FLOPs; EffNet дешевле по FLOPs в 4.3×, но
  по latency не быстрее; VRAM обучения EffNet 13.7 ГиБ vs 3.7 у ResNet. Бенчмарки прогоном
  2026-08-02 **не изменились** и совпадают с `VALUES.md` §A7.
- **Правило на будущее:** любая таблица/рисунок диссертации, защиты и демо выводится из
  `experiments/outputs/` (или из `results/`, которая их сводит) — **никогда** из
  `demo/web/data.js`. Нужен скрипт-мост outputs→рисунки (`results/TOOLING.md`).
