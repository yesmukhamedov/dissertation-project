**2026-09-24 к архиву образцов добавились видеозаписи защит.** Пяти докторантов:
Бакирова (2026-04-24), Базарбеков (2026-05-29), Дауренбаева (2025-12-25),
Момынкулов и Олжаев (оба 2026-06-25) — 0,7 ГБ, записи по 1:43–2:09.

Презентаций у совета нет и на сайте они не публикуются, поэтому слайды **собраны
из самих записей покадрово** — 174 слайда, каждый со временем появления в имени
файла. Дополняет комплект из 11 документов, разобранный в [[council-template-audit]].

## Где лежит

```
council/Образцы документов/
├── _video/<slug>/     defense_video.mp4, presentation.pdf, slides/, slides.csv,
│                      contact_sheet.jpg  + свой INDEX.md и registry.json
├── _text/<slug>/presentation.txt    распознанный текст, в общем текстовом слое
└── _tools/            extract_slides.py, ocr_slides.py, build_video_index.py
```

Материалы намеренно **вне `авторы/`**: тот каталог — зеркало сайта, его пересобирает
`organize.py`, и посторонние файлы там не выживут. По той же причине у видео
**свой `registry.json`**: дописанное в главный реестр стёр бы следующий `organize.py`.
Текст при этом лежит в общем `_text/`, чтобы поиск по архиву находил и презентации.

## Что стоило времени

- **Слайд ищется по статичности**: слайд неподвижен, живые камеры всегда шевелятся.
  Кадр с людьми отсеивается по доле однотонного фона — у слайда 0,45–0,9, у камеры
  в зале и лица крупным планом 0,07–0,25.
- **Моду яркости считать только по светлым тонам.** Чёрные поля вокруг картинки в
  Zoom тоже однотонны, и по полной гистограмме галерея камер выглядит как слайд с
  белым фоном: на записи Бакировой это дало 213 «слайдов» вместо 33.
- **Язык OCR — по слайдам из середины**, не по первому: первым кадром часто идёт окно
  Zoom с русским интерфейсом, из-за него англоязычный доклад Дауренбаевой сначала
  распознался русской моделью.
- **Кадр 640x360 увеличивается втрое** перед Tesseract: в исходном размере строка
  занимает 8–10 пикселей и не распознаётся вовсе. Языковые данные — в
  `C:\Users\yesmu\tessdata` (`TESSDATA_PREFIX`), как и в `ocr_scans.py`.
- `cv2.imwrite` **молча не пишет по кириллическим путям** на Windows — только через
  `imencode` + `tofile`. Консоль cp1251 падает на казахском `қ`: нужен
  `PYTHONIOENCODING=utf-8`.

## Ограничения

Записи в 640x360: мелкий текст в таблицах нечитаем, OCR по нему ошибается — годится
для поиска, **для цитирования открывать слайд**. Вебка перекрывает правый верхний угол
части слайдов. У Бакировой, Олжаева и Момынкулова последние слайды — не доклад, а
показанное при ответах на вопросы; отделяется по времени из `slides.csv`.
