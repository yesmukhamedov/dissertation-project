## Сравнение полярного CLAHE с классическим (IDRiD, 81 снимок, 2026-09-24)

⚠ Плиточный режим проекта (`upgraded_clahe.py`, `clahe_mode: tiles`) — **без интерполяции** между
плитками, это не классический CLAHE; на нём видны блочные артефакты, и первая версия фиг. 4 была
нечестной. Прототип в заявке — **OpenCV CLAHE 8×8, clip 2.0**. Против него полярный: искажение у
края поля зрения −28 % (61/81), радиальная неравномерность −7,6 %, шероховатость поля усиления −2,4 %
(76/81), энтропия +2,1 % (80/81), локальный контраст периферии +1,9 % (78/81) — все p < 10⁻⁴
(Уилкоксон); **но контраст микроаневризм −10,6 %, кровоизлияний −7,9 %** относительно классического.
Технический результат изобретения сформулирован как равномерность контрастирования, не как
лучшая видимость поражений.
