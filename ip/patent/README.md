# Патентные заявки в НИИС (Казпатент): полезная модель + изобретение

> **ПОДАНЫ 24.09.2026.** Полезная модель — вх. № 2026-74610 (кабинет № 504033);
> изобретение — вх. № 2026-74612 (кабинет № 504035). Дата приоритета обеих — 24.09.2026.
> Предстоящие платежи и сроки — `PROJECT_MEMORY/patent-applications.md`.

Второй трек охраны после свидетельства об авторском праве № 78109 (см. `../kazpatent/`).
Свидетельство защищает **текст программы**; патенты защищают **способ**, то есть техническое
решение, как бы оно ни было запрограммировано. Программа «как таковая» патентом не охраняется
(пп. 5 п. 3 ст. 6 Патентного закона РК), поэтому обе заявки сформулированы как **способы
обработки изображения** — процесс действий над материальным объектом (цифровым изображением)
материальными средствами (ЭВМ), п. 2 ст. 6 и п. 1 ст. 7.

## Две заявки — два разных объёма охраны

| | Полезная модель (`um/`) | Изобретение (`inv/`) |
|---|---|---|
| Объект | способ предобработки изображения глазного дна для классификации стадии ДР свёрточной сетью — весь конвейер | способ адаптивного повышения локального контраста — **полярный CLAHE** |
| Ядро новизны | совокупность: разворот левого глаза + поворот по оси ДЗН–фовеа + обрезка по полю зрения с изотропным масштабированием + маска поля зрения 4-м каналом + σ = k·D + нормализация по статистикам внутри маски | полярная сетка с центром в фовеа, кольца rᵢ = R·(i/N)^p, секторы по карте сосудистости (Гессе), гистограммы только внутри маски, интерполяция по радиусу и углу |
| Условия охраноспособности | новизна + промышленная применимость (без изобретательского уровня) | новизна + изобретательский уровень + промышленная применимость |
| Экспертиза | формальная; **по существу не проверяется**, патент «на риск заявителя» (п. 1 ст. 23) | формальная + по существу с информационным поиском (ст. 22) |
| Срок действия | 5 лет + продление на 3 года | 20 лет |
| Прототип | предобработка Грэма (Kaggle 2015) + CLAHE | CLAHE, Zuiderveld 1994 |
| Технический результат | точность и межкамерная устойчивость классификации — числа из `results/` (Exp 1, Exp 5, Exp 6) | равномерность контрастирования по полю зрения — **сравнение посчитано 2026-09-24**, `evidence/` |

Объекты разные, формулы п. 1 не совпадают — двойного патентования нет. Полярный CLAHE входит в ПМ
только зависимым п. 6.

## Порядок

1. **Кабинет.** https://newcab.kazpatent.kz, вход по ЭЦП. **До создания заявки** проверить в профиле
   тип участника = резидент (грабля 2026-09-03: тип фиксируется в заявке в момент её создания,
   см. `PROJECT_MEMORY/kazpatent-copyright-registration.md`).
2. **Две заявки** — «Полезная модель» и «Изобретение», каждая отдельно. Заявитель, автор и
   патентообладатель — кандидат единолично; не служебное (решение кандидата 2026-09-24).
   Поверенный не нужен (резидент-физлицо ведёт дела сам).
3. **Документы** (язык — русский; название дополнительно на казахском — оно уже в описаниях):
   описание (`*/opisanie.md`), формула (`*/formula.md`), чертежи (`*/figures/`), реферат
   (`*/referat.md`). **Портал принимает описание, формулу и реферат только в DOC/DOCX** (`make_docx.py`), **чертежи — только в PDF** (`make_pdf.py`, `build/*/figures.pdf`); у чертежей обязательно «№ фигуры» основного чертежа (1).
4. **Оплата** подачи — вместе с заявкой или в течение 2 месяцев с даты поступления (ст. 17, 18),
   иначе заявка не считается поданной.
5. **Изобретение:** после уведомления о положительной формальной экспертизе — оплатить экспертизу
   по существу **в течение 3 месяцев**, иначе заявка отзывается (п. 7 ст. 22). Ответы на запросы
   эксперта — 3 месяца.
6. **Выдача:** после решения о выдаче оплатить публикацию и выдачу в течение 3 месяцев.
7. В заявлении сослаться на льготу: раскрытие автором через публичный демонстратор 03.08.2026
   (при запросе эксперта — доказательства: коммит `19641e1`, архивные снимки страницы).

## Открытые вопросы

- ⚠ Плиточный режим `clahe_mode: tiles` в `experiments/src/preprocessing/upgraded_clahe.py` —
  **без билинейной интерполяции** между плитками, то есть это не классический CLAHE. В заявке
  прототипом служит настоящий CLAHE (OpenCV); на диссертацию это влияет только если где-то
  сравнивается «polar против tiles» — в `results/` такого сравнения нет.
- ⚠ Полярный CLAHE против классического — **компромисс, а не превосходство по всем метрикам**:
  равномерность, край поля зрения, энтропия и периферия — лучше; локальный контраст микроаневризм
  и кровоизлияний — ниже (−10,6 % и −7,9 %). В описании изобретения это сказано прямо, технический
  результат сформулирован только по тому, что измерено.
- Эксперт по изобретению может противопоставить уровень техники по изобретательскому уровню;
  запасной объём охраны — зависимые пп. 2–9.
