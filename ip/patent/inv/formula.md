# ФОРМУЛА ИЗОБРЕТЕНИЯ

**Способ адаптивного повышения локального контраста цифрового изображения глазного дна**

1. Способ адаптивного повышения локального контраста цифрового изображения глазного дна, включающий преобразование цветного изображения в цветовое пространство CIELAB, разбиение изображения на ячейки, построение для каждой ячейки гистограммы значений канала светлоты L, ограничение гистограммы порогом с равномерным перераспределением превышения по всем уровням, вычисление по ограниченной гистограмме таблицы преобразования светлоты ячейки, получение преобразованного значения светлоты каждого пикселя интерполяцией значений, даваемых таблицами преобразования соседних ячеек, и обратное преобразование в исходное цветовое пространство с неизменными каналами a и b, отличающийся тем, что формируют бинарную маску поля зрения, задают полярную систему координат с центром в точке фовеа, а при отсутствии достоверного определения положения фовеа — в центроиде маски поля зрения, разбивают поле зрения на N концентрических колец, радиусы границ которых определяют как rᵢ = R·(i/N)^p, i = 0, 1, …, N, где R — наибольшее расстояние от центра полярной системы до пикселя поля зрения, p > 1, вычисляют карту выраженности кровеносных сосудов по собственным значениям матрицы Гессе канала светлоты на нескольких пространственных масштабах, разбивают каждое кольцо на угловые секторы переменной ширины, границы которых устанавливают в угловых положениях с повышенной средней выраженностью сосудов в кольце при условии, что каждый сектор охватывает не менее заданной доли площади поля зрения, гистограмму каждой ячейки, образованной пересечением кольца и сектора, строят только по пикселям внутри маски поля зрения, преобразованное значение светлоты пикселя получают билинейной интерполяцией в полярных координатах — по углу между таблицами преобразования двух соседних секторов кольца с циклическим замыканием последнего сектора на первый и по радиусу между результатами для двух соседних колец, а пиксели вне маски поля зрения оставляют без изменения.

2. Способ по п. 1, отличающийся тем, что порог ограничения гистограммы ячейки задают равным меньшему из значений c₁·S/256 и c₂·S, где S — число пикселей ячейки внутри маски поля зрения, c₁ и c₂ — постоянные коэффициенты, выбираемые в диапазонах c₁ = 0,5…2,5 и c₂ = 0,01…0,05.

3. Способ по п. 1, отличающийся тем, что границы угловых секторов кольца определяют, разбивая кольцо на M элементарных угловых интервалов равной ширины, вычисляя для каждого интервала среднюю выраженность сосудов по пикселям кольца внутри маски поля зрения, сглаживая полученный ряд скользящим средним с циклическим продолжением и последовательно накапливая интервалы, причём границу сектора устанавливают после интервала, сглаженная выраженность сосудов в котором превышает медиану сглаженных ненулевых значений по кольцу, если накоплено не менее m_min интервалов и не менее заданного числа пикселей, либо после накопления m_max интервалов и не менее заданного числа пикселей.

4. Способ по п. 3, отличающийся тем, что сектор, число пикселей которого меньше заданного, итеративно объединяют с меньшим по числу пикселей из соседних секторов, пока все секторы кольца не будут содержать не менее заданного числа пикселей, а кольцо, содержащее в целом менее заданного числа пикселей, рассматривают как один сектор.

5. Способ по п. 3, отличающийся тем, что M = 72, m_min = 2, m_max = 6, ширина окна скользящего среднего составляет 5 интервалов, а заданное число пикселей составляет 1 % от числа пикселей маски поля зрения.

6. Способ по п. 1, отличающийся тем, что N = 8 и p = 1,5.

7. Способ по п. 1, отличающийся тем, что выраженность сосудов в пикселе на масштабе s вычисляют как s²·λ², если меньшее собственное значение λ матрицы Гессе канала светлоты, сглаженного гауссовым фильтром со среднеквадратичным отклонением s, отрицательно, и как ноль в противном случае, итоговую карту получают как поэлементный максимум по масштабам s ∈ {1; 1,5; 2; 3} пикселя, нормированный к диапазону [0; 1], а значения вне маски поля зрения обнуляют.

8. Способ по п. 1, отличающийся тем, что положение фовеа определяют предварительно обученной нейронной сетью регрессии тепловых карт с оценкой достоверности и используют в качестве центра полярной системы координат только при достоверности не ниже заданного порога и попадании точки внутрь маски поля зрения.

9. Способ по п. 1, отличающийся тем, что ячейку, содержащую менее 10 пикселей внутри маски поля зрения, преобразуют тождественной таблицей преобразования.

10. Способ по п. 1, отличающийся тем, что его применяют к изображению глазного дна, предварительно подвергнутому коррекции неравномерности освещённости, а полученное изображение используют в качестве входных данных свёрточной нейронной сети, классифицирующей стадию диабетической ретинопатии.

11. Способ по п. 10, отличающийся тем, что при обучении свёрточной нейронной сети повышение локального контраста применяют к каждому обучающему изображению с вероятностью 0,8, а при классификации — всегда.
