# РЕФЕРАТ

**Способ адаптивного повышения локального контраста цифрового изображения глазного дна**

Изобретение относится к цифровой обработке медицинских изображений и может быть использовано в системах автоматизированного анализа изображений глазного дна, в том числе для классификации стадии диабетической ретинопатии. Способ включает выравнивание гистограммы канала светлоты L (CIELAB) по ячейкам с ограничением гистограммы и интерполяцией таблиц преобразования. Ячейки задают полярной сеткой с центром в фовеа или в центроиде маски поля зрения: кольца с границами rᵢ = R·(i/N)^p, p > 1, делят на угловые секторы переменной ширины, границы которых определяют по карте выраженности сосудов, вычисленной по собственным значениям матрицы Гессе. Гистограммы строят только внутри маски поля зрения, интерполяцию выполняют по радиусу и углу. Технический результат — повышение равномерности контрастирования по полю зрения, снижение искажения яркости у его границы, повышение энтропии изображения. 10 з. п. ф., 4 ил., 1 табл.
