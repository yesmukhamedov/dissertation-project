# Заключение этической комиссии — оформление собственного бланка МУИТ

> **Разобрано 2026-09-19** по двум пустым бланкам, которые МУИТ выдаёт докторантам
> (`Заключение_Этической_комиссии_бланк_{рус,каз}.docx`, лежат в `D:\personal\phd\council\`
> вне репозитория). Бланки только **читались**, не правились. Всё, что задаёт внешний вид, — страница,
> шрифты, интервалы, ширины колонок, тексты строк, подписанты — снято в
> `defense/docs/ethics/form_layout.json`, поэтому ни этот файл, ни генератор бланков не требуют.
> Содержание строк — в [[структура]]. Образцы 16 докторантов (заполненные заключения) — другой
> архив, на оформление не влияли.

## Страница и шрифт

| | |
|---|---|
| Формат | А4, книжная, **одна страница** |
| Поля | верх 20 мм · низ 20 мм · **лево 30 мм · право 15 мм** (850 twips; у тома по ГОСТ — 10 мм) |
| Шрифт | Times New Roman везде; язык прогонов `ru-RU` / `kk-KZ` |
| Заголовок | 12 pt **полужирный**, по центру |

## Шапка

| RU | KZ |
|---|---|
| `ЗАКЛЮЧЕНИЕ` / *(пустая строка)* / `Этической комиссии` / `АО «Международный университет информационных технологий»` (после — 15 pt) | `Халықаралық ақпараттық технологиялар университетінің` / `Әдеп комиссиясының` / *(пустая строка)* / `ҚОРЫТЫНДЫСЫ` |

Казахская комиссия здесь — **Әдеп комиссиясы**, а не «Зерттеулерді этикалық бағалау жөніндегі комиссия»
(так у Ибраевой). Бланк новее и главнее.

## Таблица

Одинарные чёрные рамки 0,5 pt, 9 строк, строки-шапки нет. Поля ячейки: 5 pt сверху и снизу, 7,5 pt по бокам.

| | RU | KZ |
|---|---|---|
| Колонки (twips) | 2: **4390 / 4970** = 9360 | 3: **704 / 4111 / 4536** = 9351 |
| Номера строк | нет | в 1-й колонке, по центру, к верху ячейки |

Формулировки строк — в `form_layout.json` дословно. Они отличаются от [[структура]], снятых с образцов:
строка 2 — «Специальность (образовательная программа) докторантуры», строка 3 по-казахски —
«Докторантурада оқу **кезеңі**» (в образцах *мерзімі*).

## Под таблицей

1. Заключительная фраза — «Научные исследования докторанта **⟨Ф.И.О.⟩** на тему «⟨тема⟩» полностью
   соответствует этическим нормам и может быть реализовано в нынешнем виде.» (по-казахски — «Докторанттың
   ⟨…⟩ «⟨…⟩» тақырыбындағы ғылыми зерттеулері әдеп нормаларына толық сәйкес келеді және қазіргі
   нұсқасында жүзеге асырылуы мүмкін.»)
2. Две подписные строки — председатель, затем секретарь; затем строка даты.

| | RU | KZ |
|---|---|---|
| Председатель | `Председатель Этической комиссии` / `по оценке научных исследований АО «МУИТ»` `_____ Дузбаев Н.Т.` | `Әдеп комиссиясының төрағасы` `_____ Дузбаев Н.Т.` |
| Секретарь | `Секретарь` `_____ Есмурзаева А.Б.` | `Әдеп комиссиясының хатшысы` `_____ Есмурзаева А.Б.` |
| Дата | `Дата выдачи: ______ 2026 года` | `Берілген күні: ______ 2026 жыл` |

**В бланке 2026 г. председатель — Дузбаев Н.Т.** В [[структура]] стоит Найзабаева Л.К. — так в более
старых образцах; бланк новее.

## Чем бланк отличается от формы в [[структура]]

- **9 строк, без ИИ-строк.** [[структура]] рекомендует 12-строчную форму (Базарбеков). В бланке МУИТ
  строк 10–12 нет; генератор следует бланку. Как фиксируется заявление об ИИ — открытый вопрос,
  см. [[../00-нормативная-база/использование-ии]].
- **Строки 7–9 в RU-бланке уже заполнены** («Нарушения не выявлены» ×2; «В работе объекты живой
  природы и среды обитания не исследовались»). В KZ-бланке строка 8 пуста, а в строке 9 стоит
  «Бұзушылықтар анықталмады» — ошибка копирования: это ответ на другой вопрос.

## Что генератор делает иначе

`defense/docs/ethics/build_ethics_conclusion.py` собирает документ по `form_layout.json`. С флагом
`--blank` он воспроизводит бланк дословно; в рендере Word все линии таблицы и слова стоят на тех же
координатах, что в оригинале (сверено до 0,1 pt; при 100 dpi всё ещё отличаются 33 RU / 303 KZ пикселя
из 967 590, причину не искал).
Собранный документ отступает от бланка в пяти местах, все ради **одной страницы**:

1. пустой абзац-распорка между заключительной фразой и подписями убран;
2. две пустые строки перед датой — одна;
3. лишний абзац из пяти пробелов перед заключительной фразой в KZ-бланке убран;
4. подписи выровнены табуляцией, а не пробелами (в бланке линии подписей двух подписантов не
   стоят на одной вертикали);
5. строка 6 держится в 2–3 строки — поимённый перечень наборов данных есть в томе.

## Откуда берётся содержимое

| Строка | Источник |
|---|---|
| 1, 2 | `candidate.name_*`, `programme.code` + `programme.name_*` |
| 3 | `candidate.study_period` — **в реестре пусто → `<…>`** |
| 4 | `dissertation.title_*` + приказ `№ 7-D` от 27.08.2022 (`topic_approval_*`) |
| 5 | `supervisor.*`, `foreign_consultant.*`; место — организации, не гражданство (как в образцах) |
| 6 | `defense/docs/ethics/conclusion.toml` |
| 7, 8 | печатает сам бланк (вывод комиссии) |
| 9 | `conclusion.toml` — **пусто намеренно → `<…>`** |
| Подписанты | бланк (`Дузбаев Н.Т.`, `Есмурзаева А.Б.`); переопределение — `[signatories]` |
| Дата | `ethics.conclusion_date`; пусто → `______ 2026` |

Строка 9 не заполнена по умолчанию: печатный ответ бланка («объекты живой природы не исследовались»)
может не подходить работе с клиническим набором; образец Базарбекова — в [[структура]].

## Пересобрать

```powershell
python defense/docs/ethics/parse_form.py                      # только если МУИТ сменит бланк
python defense/docs/ethics/build_ethics_conclusion.py         # → ETHICS_CONCLUSION_{RU,KZ}.docx/.pdf
python defense/docs/ethics/build_ethics_conclusion.py --blank --out <каталог>   # проверка точности
```

Сборка завершается с ненулевым кодом, если документ не ровно на одной странице.
