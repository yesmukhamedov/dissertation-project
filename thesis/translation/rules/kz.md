TARGET LANGUAGE: KAZAKH (академиялық қазақ тілі, қорғалатын нұсқаның стилі)
- Decimal separator is a POINT: 0.8393. Thousands are separated by a space: 35 126.
- Citations: "Gulshan et al. (2016)" -> "Gulshan т.б. (2016)"; "(Kusuhara et al., 2018; Morya et al., 2024)" ->
  "(Kusuhara т.б., 2018; Morya т.б., 2024)"; "Wang and Lo (2018)" -> "Wang пен Lo (2018)" (пен/мен/бен by
  vowel harmony of the preceding name). NEVER write "және әріптестері" - it is a forbidden calque.
- The copula dash is the SHORT dash with spaces " – " (Мақсат – ...). Never the long dash —.
- "Сондықтан" opens a sentence; it does not follow a comma. Inside a sentence join cause with the suffix
  -дықтан/-діктен/-тықтан/-тіктен instead of ", сондықтан".
- Sentences at most ~40 words; split longer ones.
- Do not repeat one connective: vary among Демек, Сондықтан, Сонымен, Осылайша, Яғни, Тиісінше, сол себепті,
  and prefer no connective at all when the logic is clear.
- Verb at the end of the clause; attributive participle clauses before the noun (English "which/that" clauses
  become -ған/-атын/-етін participles). Do not keep English word order under Kazakh words.
- No Russian loanwords when a Kazakh academic word exists (use the TERMINOLOGY list); no Russian endings on
  Latin names (EfficientNet-B3 үшін, EyePACS-те - Kazakh suffix after a hyphen).
- Chapter/section references: "Chapter 3" -> "3-тарау", "Section 3.4" -> "3.4-бөлім", "Table 3.9" -> "3.9-кесте",
  "Figure 3.4" -> "3.4-сурет", "Diagram C.2" -> "Б.2-диаграмма" (number first, never «Сурет Б.2»/«Схема Б.2»).
- Appendix letters are Kazakh: A->А, B->Ә, C->Б, D->В, E->Г, F->Ғ. "Appendix B" -> "Ә қосымшасы",
  "Appendix C" -> "Б қосымшасы". Figure markers keep Latin: FIG-C.1, FIG-D.2 stay as they are.
- "binding" (obligatory) is «міндетті», never «байланыстырушы»; "source" (domain/corpus) is «бастапқы», never «көз» (= eye).
- "almost/nearly" is «дерлік» or «-ға жуық» (дерлік барлығы, дерлік бірдей), never «дегенде».
- Word traps (wrong -> right): network head бастық -> бас; table/matrix cell жасуша -> ұяшық; threshold есік -> табалдырық;
  floor (lower bound) еден -> төменгі шек; fold қат -> фолд; clinician клиника/клиник -> дәрігер; patient case жағдай -> іс;
  lesion лезия/жарақат -> зақымдану; pupil шәкіл -> қарашық; vessel ыдыс -> тамыр; grade деңгей -> дәреже; class сынып -> класс;
  decomposition жіктеу -> ыдырату (жіктеу = classification); coarse қатаң -> дөрекі; representation көрініс -> репрезентация;
  claim (verb) талап ету -> мәлімдеу; measured өлген -> өлшенген; augmentation өсу/өңдеу -> аугментация.
- "The candidate" -> "кандидат" (as in the approved volume).
- Russian abbreviations are never kept in Kazakh: БА (болезнь Альцгеймера) -> АА, ИИ -> ЖИ, ИМУ -> IMU,
  ЗРК -> ҚРЗ, АО -> АҚ, РК -> ҚР. МРТ, ПЭТ, ЭЭГ are the same in both languages.
- Russian calques are errors: нейросеттік -> нейрондық желі; сверткалық -> конволюциялық; локальды -> жергілікті;
  детекциялау -> анықтау; компенсациялау -> өтеу; процедура -> рәсім; машиналық оқу -> машиналық оқыту;
  майда моторика -> ұсақ моторика; рывок -> жерк; почерк -> жазу (қолжазба), never «жазу қолы».
- With the copula dash no «болып табылады»: «Зерттеу нысаны – X.», not «Зерттеу нысаны – X болып табылады.»
- An English/Russian sentence with two or more "which/который" clauses becomes two or three Kazakh sentences, each
  ending in a finite verb: "Let's take a closer look at the architecture, which consists of X, which provides Y" ->
  «Архитектураны толығырақ қарастырайық. Ол X-тен тұрады. X Y-ті қамтамасыз етеді.»
- "We applied/verified" -> impersonal passive: «қолданылды», «тексерілді» (not «біз қолдандық»).
- A Russian passive with an agent («подписывается председателем», «учитываются докторантом», «оглашаются
  секретарем») becomes a Kazakh ACTIVE clause: agent = subject, the object keeps its case:
  «хаттамаға төраға қол қояды», «ескертулерді докторант ескереді», «пікірлерін хатшы жария етеді».
  Never «хаттамасы төраға қол қояды» / «ескертулер докторант ескеріледі».
