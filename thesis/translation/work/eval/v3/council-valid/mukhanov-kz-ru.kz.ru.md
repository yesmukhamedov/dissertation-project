## ЧАСТЬ 1: ТЕКСТ РАЗДЕЛА

Цель исследования. Разработка и применение методов распознавания изображений высокой точности. Для этого необходимо использовать инструменты искусственного интеллекта, а именно алгоритмы и библиотеки для работы с машинным обучением и нейронными сетями глубокого обучения (язык программирования Python). Собрать обучающие данные и выполнить их предобработку для обучения нейронных сетей. Выполнение математических вычислений для определения градиента функций, алгоритма обратного распространения и функций активации для каждого нейрона имеет важное значение. Применить эмпирический подход к разработке архитектуры собственной модели нейронной сети для выбора обучающих параметров и гиперпараметров. Архитектура данной модели может различаться по глубине и ширине нейронной сети, поэтому количество обучающих параметров определяется произвольно. Диссертационная работа направлена на исследование задач классификации и распознавания движений, подготовленных на собственных данных (изображения, полученные из видеопотока, снятого через веб-камеру или мобильное устройство, и разделённого на кадры). Методы супервизорного обучения и глубокого обучения позволяют значительно расширить диапазон задач, эффективно решаемых в режиме реального времени в области распознавания жестов. Разработка программного обеспечения позволяет проверить эффективность обученной модели и использовать её в лабораторных целях, а также внести исправления для улучшения данной модели. Достижение данной цели приводит к повышению эффективности и расширению возможностей современных систем компьютерного зрения и распознавания жестов.

Для достижения данной цели необходимо было решить следующие задачи:

1. Сбор и предобработка данных (изображения букв, представленных в виде жестов рук казахского тюркского алфавита) для подготовки обучающей выборки для методов машинного и глубокого обучения.

2. Анализ архитектур глубокого обучения и применение методов распознавания жестов.

3. Обучение нейронной сети распознаванию казахского тюркского алфавита с использованием собственных данных (изображений).

4. Сравнение свёрточных и рекуррентных нейронных сетей глубокого обучения.

5. Разработка программного обеспечения для распознавания жестов (казахский тюркский алфавит) в режиме реального времени.
