## 1-БӨЛІК: БӨЛІМ МӘТІНІ

3.1-бөлімде алдын ала өңдеу мен оқыту кодын осы жерде толық келтіру міндеттелді, сонда әр кескінге қолданылған түрлендіру тек сөзбен сипатталып қана қоймай, бастапқы код ретінде қалпына келтірілетін болады. Бұл қосымша сол міндетті орындайды. Оның қосылуы кездейсоқ құжаттама емес. Бұл жұмыстың орталық тезисіне сәйкес, модель – алдын ала өңдеу мен конволюциялық нейрондық желінің құрамы болғандықтан, алдын ала өңдеудің бастапқы коды модель спецификациясының бөлігі болып табылады. Оны толық келтіру сол тезисті тек тұжырымдалған ғана емес, тексеруге жарамды етеді.

Код `experiments/src/` астындағы Python пакеті ретінде ұйымдастырылған. Алдын ала өңдеу стегі `experiments/src/preprocessing/` ішінде орналасқан; оның ашық интерфейсі `__init__.py` файлынан экспортталады, ал оның оркестраторы `pipeline.py` файлындағы `PreprocessingPipeline` 2-тарауда көрсетілген ретпен сегіз кезеңді тізбектейді.

Қалған құралдар туыс қосымша пакеттерге бөлінген. `data/` деректер жиындарының жүктегіштерін, пациент деңгейінде стратификацияланған бөлгішті, біріктірілген аугментацияны және этикеттерді үйлестіруді қамтиды; `models/` екі backbone фабрикасы мен екі кезеңді дәлдеп баптау утилитасын; `training/` оқыту циклін, салмақты focal loss және чекпоинттерді басқаруды қамтиды.

`evaluation/` метрикаларды, калибрлеуді және статистикалық тестерді, `explainability/` назар карталарын және қабаттаманы рендерлеуді, `experiments/` эксперимент драйверлерін, ал `utils/` конфигурацияны өңдеуді, қайталанымдылыққа арналған seed утилитасын және кескін сапасы метрикаларын қамтиды. Төмендегі каталог тек алдын ала өңдеу пакетіне шектелген; кеңірек ағаш тек келтірілген кодтың толық құрылымдағы орнын табуға болатындай етіп аталды.

А.1-кесте 2-тараудағы әр конвейер кезеңін оны іске асыратын модульге сәйкестендіреді. Әр жол репозиторийдің түбіріне қатысты берілген және нұсқаланған бастапқы код ағашында бар файлға сәйкес келеді.

**А.1-кесте – Конвейер кезеңі → іске асыратын модуль (`experiments/src/preprocessing/`).**

| Кезең | Сипаттама (2-тарау) | Іске асыратын модуль |
|-------|--------------------|---------------------|

| 5 | Екі шартты CLAHE (LAB L-арнасы; оқыту кезінде стохастикалық) | `upgraded_clahe.py`, `polar_clahe.py`, `clahe.py` |

5-кезең бірнеше модуль арқылы іске асырылады, себебі конвейер қазіргі уақытта екі шартты CLAHE-нің полярлық нұсқасын (`polar_clahe.py`) әдепкі нұсқа ретінде ұсынады, тік сызықты торкөзге негізделген формулировкамен (`upgraded_clahe.py`) қатар. Екеуі де нұсқаланған бастапқы кодта бар және каталогтағыдай толық келтірілген. 0–5-кезеңдер мен 7-кезең оқыту мен инференс кезінде бірдей қолданылады, бірақ 5-кезеңдегі контрастты күшейту оқыту кезінде стохастикалық болады. 6-кезең аугментациясы тек оқыту кезінде қолданылады және 7-кезең нормализациясынан бұрын енгізіледі. Осылайша, ол `uint8` кескіндерімен жұмыс істейді. Базалық тармақ 0–6-кезеңдерді айналып өтеді: оның орнына кескін 512x512 өлшеміне созылып масштабталады, содан кейін үш арнада жалпы нормалау жасалады; бұл нұсқа конвейерді өзгерту арқылы емес, конфигурация пресеті арқылы таңдалады. Интеграцияланған тармақ сегіз кезеңнің бәрін орындайды және төрт арна шығарады: үш түсті арна және көру алаңының маскасы.

Бұл каталог нақты бастапқы кодтың парафразы емес, оның өзін қайталайтынын дәлелдеу үшін, 4-кезеңнің flat-field модулі `experiments/src/preprocessing/flat_field.py` файлынан сөзбе-сөз келтірілген:

```python
"""
Stage 4: Flat-Field Correction.

Reduces uneven illumination by subtracting a heavily blurred version of the
image and re-centering at 128:

 corrected = image − GaussianBlur(image, σ) + 128

A large σ captures only the low-frequency illumination gradient, so the
subtraction removes broad brightness variation while preserving local vessel
and lesion detail.

σ is computed adaptively as σ = 0.07 × FOV_diameter. Correction
is applied only inside the FOV mask (padding pixels are left at zero).

Input/output images are RGB uint8 NumPy arrays.
"""

from __future__ import annotations

import cv2
import numpy as np

def apply_flat_field(
 image: np.ndarray,
 sigma: float = 45.0,
 mask: np.ndarray | None = None,
) -> np.ndarray:
 """
 Apply flat-field correction to reduce uneven illumination.

 Algorithm::

 blur = GaussianBlur(image, σ)
 corrected = image − blur + 128

 When *mask* is provided, correction is applied only inside the mask
 (``mask > 0``). Padding areas (``mask == 0``) are left at zero.

 Kernel size is derived automatically from *sigma* (passed as ``(0, 0)``
 to:func:`cv2.GaussianBlur`).

 Args:
 image: RGB uint8 NumPy array of shape ``(H, W, 3)``.
 sigma: Gaussian blur σ controlling the spatial scale of the
 illumination estimate.
 mask: Optional binary mask of shape ``(H, W)`` (float32 or uint8).
 When provided, only pixels where ``mask > 0`` are corrected;
 padding regions remain zero.

 Returns:
 Corrected RGB uint8 NumPy array of shape ``(H, W, 3)``.
 """
 blur = cv2.GaussianBlur(image, (0, 0), sigma)
 corrected = image.astype(np.float32) - blur.astype(np.float32) + 128.0
 corrected = np.clip(corrected, 0, 255).astype(np.uint8)
 if mask is not None:
 mask_3ch = np.expand_dims(mask > 0, axis=-1).astype(np.uint8)
 corrected = corrected * mask_3ch # zero out padding
 return corrected
```

Қалған модульдер сол конвенцияларға бағынады: тип-көрсеткіштері бар қолтаңбалар, `Args`/`Returns` docstring-тері, конфигурациядан шешілетін жолдар (hardcoded емес) және барлық жерде `pathlib.Path`. Олар сол пакеттен толық көлемде келтірілген.

Конвейердің шығу тегі кандидаттың контрастты күшейту және алдын ала өңдеу мен жіктеуді интеграциялау бойынша бұрын жарияланған жұмыстарынан бастау алады; олар бүкіл мәтінде бұрынғы өз жұмысы ретінде сілтеме жасалады. Мұнда келтірілген бастапқы код осы бағытты 2-тарауда айқындалған, нұсқалық сегіз кезеңді жүйеге біріктіреді.

Бастапқы код баламалы жабдықта қайта жаңғыртылуы мүмкін, бірақ оның көрсететін есептеу тиімділігінің сипаттамалары құжатталған конфигурацияға ғана тән, оны қайта жасау арқылы өнімділік, дәлдік немесе орналастыруға дайындық туралы ешқандай тұжырым жасалмайды. Бастапқы код каталогқа енгізіліп, бір модульдің дискідегі нақты іске асыру екені көрсетілгендіктен, 3.1-бөлімде басталған қайта жаңғыртылымдылық циклі аяқталады: 3.2-кестедегі бекітілген конфигурация, құжатталған аппараттық құрылғы және осы нұсқалық код бірге эксперименттік конвейерді қалпына келтіруге мүмкіндік береді.
