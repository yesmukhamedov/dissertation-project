# Объект, предмет и методы исследования

## На слайде

**Объект** — процесс автоматической многоэтапной диагностики диабетической ретинопатии по цветным снимкам глазного дна с помощью свёрточных сетей: от снимка, вышедшего из камеры, до степени, которую выдаёт модель.

**Предмет** — методы объединения предобработки с классификацией и свойства конфигурации: диагностическая точность, переносимость, согласованность внимания с патологией, поведение по камерам.

**Методы** — контролируемый факторный эксперимент 2×2; кумулятивная абляция; 5-кратная кросс-валидация, стратифицированная на уровне пациента; тесты DeLong и McNemar, поправка Холма, bootstrap, модель смешанных эффектов; Grad-CAM; доменное расстояние MMD / KL.

## Речь

Объект — процесс автоматической диагностики ретинопатии по цветным снимкам глазного дна, целиком, начиная с камеры. Предмет — методы объединения предобработки с классификацией и свойства конфигурации. Основной метод — контролируемое сравнение: фиксируется всё, кроме изучаемого фактора.
