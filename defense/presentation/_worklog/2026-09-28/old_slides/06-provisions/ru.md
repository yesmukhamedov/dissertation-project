# Положения, выносимые на защиту

## На слайде

1. **Восьмиэтапный конвейер предобработки снимков глазного дна**, формализованный как компонент модели (каноническая ориентация, изотропное масштабирование, маска поля зрения 4-м каналом, коррекция освещённости σ = 0,07·D, CLAHE с клип-лимитом как минимумом двух ограничений, θ* = (2,5; 0,03)); вклады этапов разделимы: взвешенный F1 монотонно растёт **0,754 → 0,819**, **41 %** прироста дают два фотометрических этапа *(H-2)*
2. **Интегрированная конфигурация «конвейер + CNN»** превосходит базовую на 35 126 снимках EyePACS для обеих архитектур: взвешенный F1 **+6,5 п.п.**, ROC-AUC **+0,03**, κ **+0,11** (p < 0,01 с поправкой Холма), взаимодействия с архитектурой нет *(H-1)*
3. **Конвейер обеспечивает переносимость:** расстояние до каждого из шести внешних корпусов сокращается (MMD **−0,070…−0,093**); на APTOS F1 **+0,089** (G 0,898 против 0,858); разброс между пятью группами камер уже в **2,4 раза**; на IDRiD и Messidor-2 **+0,069 / +0,054** (выше MCID 0,05) *(H-3, H-4, H-6, H-7)*
4. **Асимметричная мера согласованности внимания с экспертной разметкой (ALO):** в интегрированной конфигурации выше по всем четырём типам поражений, **+0,099…+0,129**, p ≤ 0,015 *(H-5)*

## Речь

На защиту выносятся четыре положения.
Первое — восьмиэтапный конвейер, формализованный как компонент модели. Вклады этапов разделимы: при последовательном добавлении этапов F1 растёт с 0,754 до 0,819 монотонно во всех пяти фолдах, 41 процент прироста дают два фотометрических этапа.
Второе — интегрированная конфигурация на обеих архитектурах выше базовой: по F1 на 6,5 процентного пункта, по AUC на 0,03, по каппе на 0,11, эффект не зависит от архитектуры.
Третье — конвейер обеспечивает переносимость: расстояние до шести внешних корпусов сокращается, а на невиденных, приборных и клинических корпусах интегрированная конфигурация выше.
Четвёртое — асимметричная мера согласованности внимания с разметкой; по ней согласованность выше для всех четырёх типов поражений.
