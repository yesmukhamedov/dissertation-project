# Эксперимент 2: абляция этапов конвейера

## На слайде

Рисунок: слева — этапы добавляются по очереди (каскад, Δ п.п.); справа — оптимум CLAHE (клип-фактор 2,5, порог 0,03) и коррекции освещённости (σ/D = 0,07) (`img/exp2_ru.png`)

## Речь

Второй эксперимент при одной инициализации добавляет этапы по очереди. F1 растёт с 0,754 до 0,819 монотонно в каждом из пяти фолдов — выигрыш первого эксперимента целиком воспроизводится предобработкой. Каждый шаг больше шума; наибольший вклад — коррекция освещённости и CLAHE, вместе 41 процент. У их параметров есть внутренний оптимум: клип-фактор 2,5, порог 0,03, масштаб коррекции 0,07. Основные конфигурации обучены при 2,0 и 0,01 — не в оптимуме, так что результат не завышен подбором.
