# Анализ существующих подходов

## На слайде

| Направление | Что делают | Пробел |
|---|---|---|
| Архитектурное (ансамбли, CNN+ViT, attention) | точность растёт за счёт усложнения архитектуры | предобработка не контролируется и не описывается |
| Предобработка (CLAHE, нормализация) | подготовка данных; параметры по умолчанию | нет абляции, параметры не формализованы |
| Перенос между корпусами | адаптация на данных целевого домена | механизм не измеряется, только следствие |
| Интерпретируемость (Grad-CAM) | качественные тепловые карты | нет количественной меры согласованности с разметкой |
| Внедрённые системы [58], [62] | проспективные испытания (чувствительность 87,2 %, специфичность 90,7 %) | предобработка не раскрыта |

**Принято:** 𝒫(I) → данные → ŷ = CNN(данные)   **Предлагается:** ŷ = CNN_θ(𝒫(I)), 𝒫 — компонент модели

## Речь

Существующие работы проанализированы по пяти направлениям. Большинство повышает точность усложнением архитектуры, а предобработку применяет с параметрами по умолчанию и без абляции; механизм переноса не измеряется; интерпретируемость ограничена качественными картами; внедрённые системы предобработку не раскрывают. Поэтому предобработка включается в выражение модели, а её эффект проверяется контролируемым экспериментом.
