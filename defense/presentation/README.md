# Презентация защиты — kk / ru / en

Презентация собирается на трёх языках с 2026-09-26. Основа — архивная (казахская, 39 слайдов) в
`defense\_archive\presentation_2026-09-26\` (опись — `INVENTORY.md` там же). **С 2026-09-28 по указанию докторанта:**
слайды архива 11–21, 23–33, 38 и титулы сохраняются (с 17-го снят GIF — анимация запрещена), остальные переработаны;
диссертация — не источник истины для положений (они переписаны по образцам совета), числа — только из `results\`.
План — `PLAN.md`, решения и находки — `report\REPORT.md`.

## Три принципа

1. **Три языка сразу.** Каждый слайд — одна папка, в ней `kk.md`, `ru.md`, `en.md`. Правка смысла делается во всех
   трёх одновременно; если один язык отстаёт — в его шапке `status: behind`.
2. **Общий словарь.** Термины и рубрики — из `glossary\` (kk/ru/en + история правок). Где можем — берём слово, которым
   уже пользовались докторанты этого совета, и записываем, у кого и на каком слайде оно стоит (`usage.csv`).
   Наше собственное употребление тоже пишем в `usage.csv` (slug `A17`, номер нашего слайда).
3. **Каждое решение обосновано.** У каждого слайда `analysis.md`: зачем слайд, по чьему образцу, что взято и что
   сделано иначе, какие термины и откуда, откуда каждое число (`dissertation\results\`). Из них собирается PDF-отчёт.

## Папки

```
presentation\
  README.md            этот файл
  PLAN.md              порядок слайдов, образец и время на каждый (утверждается до текстов)
  _templates\          шаблоны kk/ru/en.md и analysis.md
  slides\NN-id\        kk.md  ru.md  en.md  analysis.md  (+ картинки слайда, если свои)
  glossary\            словарь: serve.py, index.html, terms.csv, usage.csv, history.csv, usage.md
  report\              сборка PDF-отчёта по analysis.md
  build\               собранные презентации (pptx/pdf) по языкам — только результат, руками не править
```

## Словарь

Запуск: `python glossary\serve.py` → откроется http://localhost:8765.
Правка в ячейке сохраняется сразу; поле «причина правки» попадает в историю. Excel тоже можно: при следующем открытии
страницы изменения будут найдены и записаны в `history.csv` с пометкой «вне страницы» (Excel при этом лучше закрыть).
`usage.md` — читаемый список «термин → у кого, на каком слайде, цитата», пересобирается сам.

## Источники

- Образцы и оценки: `council\temp\ВЫБОР_ОБРАЗЦОВ.md`, `АНАЛИЗ_ПРЕЗЕНТАЦИЙ.md`, `АНАЛИЗ_ОФОРМЛЕНИЯ_ПРЕЗЕНТАЦИЙ.md`,
  `_ОЦЕНКА_ЗАЩИТ\{по_блокам,содержание}\`.
- Слайды других докторантов по рубрикам: `council\temp\<A..>\Презентация\NN_<рубрика>.{pdf,txt}`,
  все подряд — `00_Слайды_по_порядку.txt`; речь — `council\Образцы документов\_text\<slug>\defense_speech.txt`.
- Терминология диссертации (EN→KZ, обязательна): `thesis\glossary\GLOSSARY_EN.md`, `GLOSSARY_KZ.md` —
  словарь защиты ей не противоречит; русского там нет, его добавляем здесь.
- Числа — только `dissertation\results\`; тексты задач/положений/новизны — из введения диссертации (`thesis\`).

## Порядок работы

1. `PLAN.md` — список слайдов с образцом на каждый → согласовать.
2. Словарь рубрик (собран по 16 защитам) → выбрать формулировки → `approved`.
3. Слайды по блокам: вход → основная часть → выход. На каждый: `analysis.md` (план и образцы) → ru → kk → en → сверка чисел.
4. Сборка pptx по языкам, проверка по правилам оформления (раздел 9 `АНАЛИЗ_ОФОРМЛЕНИЯ_ПРЕЗЕНТАЦИЙ.md`).
5. PDF-отчёт из всех `analysis.md` + словаря.
