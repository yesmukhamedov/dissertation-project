## Айырмашылықтар бланктен (әдейі жасалған)

1. **Сөйлем реті.** Бланкте тақырып пен БББ екі бөлек үзінді болып тұр, арасында
   етістік жоқ — сол күйінде көшірсе, сөйлем құралмайды. Мәтін бланктің сөздерінен
   құралды, тек бір сөйлемге біріктірілді.
2. **«Келесу:» → «Келісу:».** Бланкте қате басылған; дұрысы — «Келісу».
3. Қалғаны — бланк сөздері өзгеріссіз.
