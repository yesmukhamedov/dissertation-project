fig4_flowchart.png
    Flowchart of the end-to-end inference pipeline: left+right eye input ->
    preprocessing (flip -> OD-Fovea rotation -> crop -> mask -> flat-field ->
    polar CLAHE -> normalize) -> EfficientNet-B3 (Config D) -> softmax over
    5 classes (per eye) -> patient-level aggregation
    (worst-eye rule) -> result (DR grade + referable + confidence)
    -> Grad-CAM/attention -> ophthalmologist review (confirm/reject).

fig5_architecture_artistic.png
    Artistic diagram of the EfficientNet-B3 (Config D) architecture,
    4-channel input (RGB + FOV mask, 512x512x4): Stem -> MBConv1-7 blocks
    with resolutions and channel counts labelled -> head 1x1 Conv (1536) ->
    GAP -> FC -> softmax (5 logits, DR 0-4).

fig6_model_graph.png
    Detailed graph of a single MBConv block with tensor shapes: expansion 1x1
    convolution, depthwise 3x3, Squeeze-and-Excitation (pool -> fc1 -> SiLU ->
    fc2 -> sigmoid -> channel scale), projection 1x1 convolution, stochastic
    depth (drop-path) and residual add.

fig7_pr_curves.png
    Per-class Precision-Recall curves, comparison of baseline (Config C) and
    the full pipeline (Config D), with AP reported for each class.
    The pipeline raises AP across all DR grades.

fig8_training_curves.png
    Training curves by epoch: left — validation loss, right — weighted F1
    on validation for Config A (ResNet+baseline), Config C (EffNet+baseline)
    and Config D (EffNet+pipeline). The pipeline (Config D) converges faster
    and to better values.

fig9_confusion_matrix.png
    Normalized (row-wise) confusion matrices for baseline (Config C) and
