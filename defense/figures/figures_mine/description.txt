fig4_flowchart.png
    Блок-схема сквозного пайплайна инференса: ввод левого+правого глаза ->
    препроцессинг (flip -> OD-Fovea rotation -> crop -> mask -> flat-field ->
    polar CLAHE -> normalize) -> EfficientNet-B3 (Config D) -> softmax по
    5 классам (для каждого глаза) -> агрегация на уровне пациента
    (правило худшего глаза) -> результат (степень ДР + referable + доверие)
    -> Grad-CAM/attention -> проверка офтальмологом (подтвердить/отклонить).

fig5_architecture_artistic.png
    Художественная схема архитектуры EfficientNet-B3 (Config D),
    4-канальный вход (RGB + FOV-маска, 512x512x4): Stem -> блоки MBConv1-7
    с указанием разрешений и числа каналов -> головной 1x1 Conv (1536) ->
    GAP -> FC -> softmax (5 логитов, DR 0-4).

fig6_model_graph.png
    Детальный граф одного блока MBConv с формами тензоров: расширяющая 1x1
    свёртка, depthwise 3x3, Squeeze-and-Excitation (pool -> fc1 -> SiLU ->
    fc2 -> sigmoid -> channel scale), проекционная 1x1 свёртка, stochastic
    depth (drop-path) и остаточное сложение (residual add).

fig7_pr_curves.png
    Precision-Recall кривые по классам, сравнение baseline (Config C) и
    полного пайплайна (Config D), с указанием AP по каждому классу.
    Пайплайн повышает AP на всех степенях ДР.

fig8_training_curves.png
    Кривые обучения по эпохам: слева — validation loss, справа — weighted F1
    на валидации для Config A (ResNet+baseline), Config C (EffNet+baseline)
    и Config D (EffNet+pipeline). Пайплайн (Config D) сходится быстрее и
    к лучшим значениям.

fig9_confusion_matrix.png
    Нормированные матрицы ошибок (по строкам) для baseline (Config C) и
