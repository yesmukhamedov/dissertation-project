# Demo sample pairs

Fundus images behind the Demo tab's "Random sample" button, resized
from the IDRiD Segmentation training set (26 synthetic
bilateral patients, 52 images). Generated by
`demo/web/scripts/prepare_segmentation_pairs.py`; see `patients.json`.
