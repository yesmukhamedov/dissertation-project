# ⚠️ INTEGRITY_NOTE — расхождение демо/защиты с реальными данными

**Читать перед использованием любых чисел или рисунков.**

Демо-дашборд (`demo/web/`) и рисунки защиты (`defense/figures/`) сейчас представляют **все
гипотезы подтверждёнными** на числах, которые **не совпадают с реальными выходами**
`experiments/outputs/`. В диссертацию берём ТОЛЬКО реальные числа. Демо/защиту нужно позже
пересобрать из реальных данных (академическая честность перед защитой).

## Главный пример — exp1, Weighted F1

| Config | Демо (`data.js`/`generate_charts_01_14.py`) | Реально (`outputs/exp1/summary.json`) |
|--------|---------------------------------------------|----------------------------------------|
| A | 0.724 | **0.7769** |
| B | 0.776 | **0.7810** |
| C | 0.727 | **0.7754** |
| D | 0.780 | **0.7702** |
| «прирост» B−A | +5.2пп (мнимое доминирование) | **+0.41пп** |
| «прирост» D−C | +5.3пп (мнимое доминирование) | **−0.51пп** |

Демо-числа рисуют ровно то доминирование H-1, которого в реальных данных НЕТ.

## Что заражено и подлежит пересборке/списанию

- **`demo/web/src/data.js`** — единый источник чисел дашборда. Все константы (`CONFIGS`, `ABL`,
  `ALO`, `IOU`, `GEN`, `G_RATIO`, `DEV`, `CLS`, `STAT_TESTS`, `HYPOTHESES` = «6 подтверждённых»)
  — транскрибированы вручную и расходятся с реальными данными. `HYPOTHESES` помечает H-1/H-2/H-4/H-5/H-6/H-7
  как confirmed — реально `*_supported=false` по H-1/H-4/H-6/H-7.
- **`demo/web/generate_charts_01_14.py` / `_15_28.py` / `_29_30.py`** — ~30 PNG на ЗАШИТЫХ числах
  (`CONFIGS = {'A': {'f1': 0.724, ...}}`), не читают `outputs/`. Пересобирать из реальных данных.
- **`defense/figures/scripts/fig9_confusion_matrix.py`** — матрицы `CM_C`/`CM_D` зашиты вручную.
- **`defense/figures/figures_mine/fig8_training_curves.png`, `fig9_confusion_matrix.png`** —
  скопированы из демо-PNG (`demo/public/images/results/exp1/`), т.е. на демо-числах.
- **`demo/web/CLAUDE.md`** прямо декларирует «HYPOTHESES — 6 confirmed hypotheses» и «everything
  presented as completed work» — установка, которую нужно снять при пересборке.

## Что НЕ заражено (можно доверять)

- Всё под `experiments/outputs/` — источник истины (реальные JSON/CSV из обучающих прогонов).
- `experiments/src/evaluation/metrics.py`, `statistical_tests.py`, `calibration.py` — корректный расчёт.
- Тексты уже одобренных глав (1/2/3/6 + §4.1) — они НЕ содержат экспериментальных метрик по
  построению (написаны до прогонов), поэтому не заражены демо-числами.

## Правило на будущее

Любая таблица/рисунок диссертации, защиты и демо должна выводиться из `experiments/outputs/`
(или из этой `results/` папки, которая их сводит) — **никогда** из `demo/web/data.js`. Нужен
скрипт-мост outputs→рисунки (см. `TOOLING.md`), чтобы устранить ручную транскрипцию как класс.
