# FIG-4.9 / CLAHE Threshold Sensitivity Sweep (H-2 / PC-2)

Part B: свип CLAHE clip_factor (7 значений) на IDRiD. Цель H-2/PC-2 — параметрическая
чувствительность с ≥1 локальным оптимумом, особенно в per-class F1 для DR1/DR2. Источник:
`data/exp2_clahe_sweep.json`. (Оценка на IDRiD, малая выборка → per-class шумны, DR1 часто 0.)

| clip_factor | Weighted F1 | DR1 F1 | DR2 F1 |
|-------------|-------------|--------|--------|
| 0.5 | 0.7115 | 0.000 | 0.667 |
| 1.0 | 0.7145 | **0.286** | 0.731 |
| 1.5 | 0.7149 | 0.222 | **0.807** |
| 2.0 | 0.7024 | 0.000 | 0.746 |
| 2.5 | **0.6515** (мин) | 0.000 | 0.667 |
| 3.0 | 0.7049 | 0.000 | 0.793 |
| 4.0 | **0.7235** (макс wF1) | 0.000 | 0.721 |

**Итог (H-2/PC-2 CLAHE-часть — ПОДТВЕРЖДЕНО).** Профиль явно параметрически зависим и НЕ монотонен:
есть выраженный провал при clip=2.5 (wF1 0.652) и локальные оптимумы — **DR2 F1 максимален при
clip=1.5 (0.807)**, общий wF1 максимален при clip=4.0. Существование чувствительного профиля с
локальным(и) оптимумом(ами) в тестируемом диапазоне — что и утверждает H-2 — выполнено.

**Оговорки.** (1) Оценка на IDRiD (малая, DR1 почти не представлен → F1 0 в большинстве точек — не
информативен для DR1). (2) По одной оценке на значение (нет std по фолдам) → это характеризация
чувствительности, не строгий выбор оптимума. (3) **σ-свип flat-field (0.05–0.10·D) НЕ прогнан** —
вторая половина PC-2 остаётся незакрытой (см. пробел ниже).

**Пробел (для §4.3.3).** Flat-field σ-свип отсутствует в выходах exp2 (`_meta` упоминает только
CLAHE Part B). Если нужен для PC-2 полностью — допрогнать σ ∈ {0.05..0.10}·D.
