# FIG-4.10 / Flat-Field σ Sweep (H-2 / PC-2, часть C)

Свип параметра адаптивного flat-field: σ как доля диаметра FOV, диапазон 0.05–0.10·D_FOV.
Оценка на EyePACS (train-фолды) с параллельным контролем CNR.
Источник: прогон **2026-08-02** (`VALUES.md` §2b).

> **Новое в этом прогоне.** До 2026-08-02 σ-свип не был прогнан (Part C отсутствовала в
> `exp2_ablation.py` — пробел G-5), и вторая половина PC-2 оставалась незакрытой. Теперь закрыта.

## Итог: H-2 / PC-2 (flat-field-часть) — ПОДТВЕРЖДЕНО

1. **Внутренний оптимум существует.** Профиль строго унимодален с максимумом на σ = 0.07 и
   симметричным спадом в обе стороны (0.7680 ← 0.8090 → 0.7570). Оптимум не краевой, размах по
   диапазону R = 0.052 — сопоставим с полным эффектом конвейера (+0.0655), то есть
   **чувствительность к σ высокая** и параметр требует настройки, а не выбирается произвольно.
2. **CNR и wF1 здесь сонаправлены.** Максимум CNR (3.90) приходится ровно на σ\* = 0.07, и
   ранжирование по CNR совпадает с ранжированием по wF1 во всех шести точках. Это отличие от
   картины по уровням аблации (`TAB-4.5`), где соответствия нет: **внутри одной стадии**
   контраст-к-шуму оказывается хорошим прокси качества, **между разными стадиями** — нет.
3. **Held-out подтверждает выбор:** +0.0570 wF1, CI исключает ноль.
4. Значение σ\* = 0.07 совпадает с параметром, зафиксированным в спецификации конвейера
   (Stage 4, адаптивный σ = 0.07·D) — свип подтверждает уже принятую настройку, а не меняет её.

## Оговорки

- Сетка — одна оценка на точку, без std по фолдам; шаг 0.01·D, более тонкой сетки нет.
- Абсолютные значения CNR в этой таблице (3.1–3.9) считаны в другой нормировке, нежели CNR в
  `TAB-4.5_exp2_image_quality.md` (20–29); **сравнивать между таблицами нельзя**, внутри каждой
  таблицы ранжирование корректно.
- Взаимодействие σ с параметрами CLAHE не исследовалось: свипы одномерный (σ) и двумерный
  (clip × threshold) выполнены независимо, совместная сетка из трёх параметров не строилась.
