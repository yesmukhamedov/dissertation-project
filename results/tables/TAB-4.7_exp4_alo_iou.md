# TAB-4.7 — Experiment 4: Attention–Lesion Overlap (ALO, primary) + IoU (secondary) (H-5)

Grad-CAM vs IDRiD пиксельные маски поражений. EfficientNet-B4, baseline (3ch) vs full pipeline (4ch).
**ALO = area(GradCAM ∩ lesion)/area(lesion)** — первичная метрика (покрытие поражения вниманием).
**IoU** — вторичная. Бинаризация теплокарты порогом 0.5 (канонический), сверху — проверка
устойчивости по порогу.

> **⚠️ ПЕРЕСЧИТАНО 2026-07-28 на полном наборе масок (n = 54 вместо 5). Вердикт H-5 ИЗМЕНИЛСЯ на
> «не подтверждена».** Прежний прогон сэмплировал 50 изображений из IDRiD «B. Disease Grading»
> (413 шт.), а маски лежат в «A. Segmentation» (54 шт.) — пересечение составляло **5** изображений.

**Вердикт: `h5_alo_supported = false`.** ALO выше у препроцессированной модели лишь для **2 из 4**
типов поражений (критерий — ≥3/4); IoU — тот же результат. **Ни по одному типу разница не значима**
(все p ≥ 0.38, все 95% CI включают ноль). Формулировка H-5 требует «significantly higher» — не
выполнено ни в направленной, ни в статистической части.

## Устойчивость к порогу бинаризации (ALO)

| Порог | Типов улучшено | Значимо (p<0.05) | Критерий ≥3/4 |
|---|---|---|---|
| 0.2 | 3/4 | 0/4 | ✓ (единственный) |
| 0.3 | 2/4 | 0/4 | ✗ |
| **0.5** (канонический) | **2/4** | **0/4** | ✗ |
| 0.7 | 1/4 | 0/4 | ✗ |

Направленный критерий выполняется только при самом низком пороге 0.2 и разваливается с его ростом,
тогда как **статистическая значимость отсутствует при любом пороге**. Т.е. отрицательный результат
не является артефактом выбора 0.5.

## ⚠️ Обязательные оговорки

1. **Эффект пола.** У 37 из 54 изображений ALO = 0 по всем типам в обеих арках (при пороге 0.5):
   зона активации Grad-CAM (top-области ≥0.5) попросту не пересекается с мелкими поражениями.
   Метрика работает у самой границы чувствительности — это ограничение измерения, а не только выборки.
2. **Soft exudates деградируют** (0.0242 → 0.0012, 0 улучшений из 26 изображений).
3. **INVARIANTS NC-14:** Grad-CAM активация ≠ клиническая локализация патологии.
4. Классификация арок B4 при этом остаётся в пользу конвейера (full wF1 0.7766 vs baseline 0.7545,
   `exp4_classification.md`) — внимание не выравнивается по поражениям, хотя классификация лучше.

**Как формулировать:** «на полном наборе IDRiD-масок (n = 54) препроцессированная модель не
показывает статистически значимо большего перекрытия внимания с поражениями ни по одному типу
(p ≥ 0.38); направленное преимущество наблюдается лишь у 2 из 4 типов и неустойчиво к порогу
бинаризации. Прежний положительный вердикт был получен на n = 5 и не воспроизводится при
расширении выборки».

Классификация двух арок — `exp4_classification.md`. Качественные overlays: 54 шт. в
`experiments/outputs/exp4/gradcam_maskset/*.png` (все с масками; прежние 50 — в `gradcam/`).
