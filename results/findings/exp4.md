# Выводы — Experiment 4 (Grad-CAM explainability, H-5) → §4.5 / §5.1

> **★ ПЕРЕСЧИТАНО 2026-07-28 (n масок 5 → 54). Вердикт изменился: H-5 НЕ подтверждена.**
> Ниже — актуальная версия; прежняя редакция («единственная подтверждённая гипотеза») недействительна.

**Что делали.** Обучили две арки EfficientNet-B4 (baseline 3ch vs full pipeline 4ch, fold 0),
построили Grad-CAM карты и сопоставили с пиксельными масками поражений IDRiD. Первичная метрика —
ALO (доля поражения, покрытая вниманием), вторичная — IoU. **Пересчёт:** анализ проведён на **всех
54** изображениях IDRiD, у которых есть маски поражений, с парным тестом (Wilcoxon, 1-сторонний) и
bootstrap-CI разности, а также с проверкой устойчивости к порогу бинаризации теплокарты.

**Что выяснили.**

1. **H-5 не подтверждена.** ALO препроцессированной модели выше baseline лишь для **2 из 4** типов
   поражений (критерий ≥3/4), и **ни по одному типу разница не значима** (p ≥ 0.38, все 95% CI
   включают ноль). По haemorrhages и особенно soft exudates (0.0242 → 0.0012) препроцессинг делает
   **хуже**. IoU даёт тот же результат.
2. **Прежний вердикт был артефактом выборки.** Старый прогон брал 50 изображений из IDRiD
   «B. Disease Grading», а маски лежат в «A. Segmentation» → пересечение = 5 изображений. Новый
   прогон **побитово воспроизводит** старые числа на тех же пяти: из них 2 давали нули везде, 2
   ухудшались, и всё «улучшение 3/4 типов» держалось на **одном** снимке (IDRiD_017).
3. **Отрицательный результат устойчив к порогу.** Направленный критерий ≥3/4 выполняется только при
   пороге 0.2 (при 0.3/0.5/0.7 → 2/4, 2/4, 1/4), значимости нет ни при каком пороге.
4. **Эффект пола у самой метрики.** При каноническом пороге 0.5 у **37 из 54** изображений ALO = 0
   по всем типам в обеих арках — область активации Grad-CAM просто не пересекается с мелкими
   поражениями. ALO/IoU здесь измеряют у границы чувствительности.
5. **Классификация арок при этом в пользу конвейера** — full B4 wF1 0.7766 vs baseline 0.7545
   (+2.2пп F1, +0.024 AUC). Это важный содержательный разрыв: конвейер улучшает **классификацию**,
   не улучшая **выравненность внимания** по поражениям.

**Главный вывод (для §4.5/§5.1).** Гипотеза о том, что препроцессинг направляет внимание модели на
клинически значимые структуры, на полном наборе масок **не подтверждается**. Выигрыш конвейера
существует (AUC/κ в exp1, малые данные в exp7, классификация арок здесь же), но он **не проходит
через лучшую пространственную локализацию поражений**. Это ровно то, что запрещает утверждать
INVARIANTS **NC-14**: Grad-CAM активация не является клинической локализацией патологии — и
эмпирика теперь это подтверждает, а не обходит.

**Как подавать.** «На полном наборе IDRiD-масок (n = 54) препроцессированная модель не показывает
значимо большего перекрытия внимания с поражениями ни по одному типу; направленное преимущество
есть лишь у 2 из 4 типов и неустойчиво к порогу бинаризации. Механизм выигрыша конвейера —
дискриминативный (ранжирование, чувствительность к referable-DR), а не локализационный.»

**Оговорки (обязательно в текст).** Одна фолд-0 модель на арку; EfficientNet-B4 (не B3); маски
IDRiD только для training-подмножества сегментации (54 изображения); эффект пола у ALO/IoU при
фиксированном пороге; NC-14. Качественные overlays: 54 шт. в `outputs/exp4/gradcam_maskset/`
(все с масками) + прежние 50 в `outputs/exp4/gradcam/`.
