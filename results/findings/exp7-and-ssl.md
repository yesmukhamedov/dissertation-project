# Выводы — Experiment 7 (малодатное обучение) + SSL → §4.8 / §3.3.2

## Exp 7 — IDRiD → Clinical (малые данные) → §4.8

**Что делали.** Обучение с нуля (init) на малом IDRiD (n=516, 5-fold), тест на Kazakh Clinical,
сравнение арм baseline (3ch) vs full (4ch), EfficientNet-B3.

**Что выяснили.**
1. **Full стабильно превосходит baseline на малых данных.** Clinical wF1: 0.3052 vs 0.2153
   (**Δ +0.0899**); κ 0.600 vs 0.486 (+0.114); AUC 0.750 vs 0.708 (+0.041); acc 0.327 vs 0.270.
   Bootstrap-CI по wF1 разъезжаются (baseline [0.142,0.302], full [0.214,0.403]).
2. **Стабильность по фолдам.** Внутренний idrid_val_f1 у full ≥ baseline во всех 5 фолдах.
3. **Абсолют низкий, но это ожидаемо** — тяжёлый кросс-доменный малодатный сценарий (обучение на
   516 IDRiD, тест на другой клинике). Ценность — в разнице армов, не в абсолюте.

**Значение.** Самый важный конструктивный результат работы и опора главного практического вклада:
**в режиме нехватки данных 8-стадийный препроцессинг работает как эффективный априор** и даёт
ощутимый выигрыш. Это ровно целевой сценарий диссертации (клинические данные Казахстана — малые).
Объясняет, КОГДА препроцессинг помогает: при обучении в целевом домене (contrast с exp5/exp3 —
zero-shot перенос, где не помогает).

## SSL — in-domain self-supervised pretraining → §3.3.2 / §4.2 caveat

**Что выяснили.** From-scratch in-domain SSL (BYOL/MoCo-v2/DINO) провалил linear-probe гейт
(лучший MoCo-v2 κ 0.112 << ImageNet 0.32; BYOL коллапсировал κ≈0). Пивот на continual-SSL
(ImageNet→MoCo-v2, ep50): ResNet-50 κ 0.605 vs ImageNet 0.357 (**+0.248, реальный выигрыш**),
EffNet-B3 κ 0.431 ≈ ImageNet 0.435 (**без выигрыша — честная оговорка**).

**Значение.** Робастный отрицательный результат (from-scratch fundus-SSL в рамках бюджета не
конкурентен ImageNet) + асимметрия по бэкбонам. Config B/D инициализируются continual-ep50; это
и есть источник confound CFC-2.8 для H-1.
