# H-2 — Component Ablation + CLAHE/σ Sensitivity (Exp 2) → PC-2, PC-8

**Формулировка H-2 (HYPOTHESIS.md).** Варьирование параметров dual-constraint CLAHE (и σ
flat-field) на EyePACS даёт параметрически-зависимый профиль per-class F1 (особенно DR1/DR2) с
≥1 локальным оптимумом в тестируемом диапазоне.

**Протокол факта:** аблация — 15%-подвыборка EyePACS, 3 фолда, ImageNet-init; CLAHE-свип — 7
значений clip на IDRiD; σ-свип — НЕ прогнан.

## PC-2 (чувствительность CLAHE/σ) — ЧАСТИЧНО ПОДТВЕРЖДЕНО

CLAHE-часть **ПОДТВЕРЖДЕНА**: профиль немонотонный, провал при clip=2.5 (wF1 0.652), локальные
оптимумы (DR2 F1 макс при clip=1.5 = 0.807; wF1 макс при clip=4.0 = 0.724). Существование
чувствительного профиля с оптимумом — выполнено. **σ-свип flat-field НЕ прогнан** → вторая
половина PC-2 открыта. (Оценка на IDRiD, малая выборка, DR1 F1≈0 — неинформативен.)

## PC-8 (ранжированная иерархия вклада стадий) — НЕ УСТАНОВЛЕНА (эффекты внутри шума)

Индивидуальная аблация даёт порядок ΔwF1 vs baseline (0.7611): canonical flip **+0.9пп** (единств.
плюс) > flat-field −0.1пп > CLAHE −0.8пп > full −1.5пп > augmentation −1.8пп. **Но весь разброс
уровней (|Δ| ≤ 0.018) меньше межфолдовой дисперсии (std 0.014–0.040), поэтому ранжирование на этом
n статистически не обосновано** — PC-8 как «иерархия вкладов идентифицирована» НЕ выполняется.
Обоснованно утверждать можно только более слабое: **препроцессинг-only на этом протоколе прироста
wF1 не даёт** (ни одна стадия не выводит метрику за пределы шума вверх).

> **Правка 2026-07-28.** Ранее здесь стояло `full −4.1пп` и вывод «накопление стадий снижает wF1».
> Это был артефакт: фолд 2 уровня `full` был оборван на 2-й эпохе из 20. После дообучения
> full = 0.7463 ± 0.0136 (−1.5пп), std уровня упала втрое (0.0328 → 0.0136), и `full` перестал быть
> худшим уровнем (ниже него `+augmentation`). Монотонной деградации «по мере накопления стадий»
> в данных нет.

## Честная трактовка (ключевое для тезиса)

1. **Подтверждает CFC-2.8.** Препроцессинг-only (ImageNet-init, малые данные) НЕ улучшает
   классификацию → выигрыш AUC/κ в exp1 (интегрированный арм) обусловлен композитом
   (препроцессинг + in-domain SSL-init), а не препроцессингом самим по себе. Связь: [[H-1]],
   [[exp7-and-SSL]].
2. **Качество изображения ≠ качество классификации.** Flat-field повышает CNR (20→42), но wF1 не
   растёт (см. `tables/TAB-4.5_exp2_image_quality.md`). Сильный довод для §4.3.3/§5.4.

## Оговорки

15%-подвыборка + 3 фолда → высокая дисперсия (std 0.01–0.04), различия между уровнями не значимы;
фолд 2 уровня `full` дообучен отдельным запуском (разбиение то же, состояние ГСЧ отличается от
фолдов 0/1); отсутствует уровень +OD-fovea rotation; σ-свип не прогнан; CLAHE-свип на IDRiD без std.
Числа не сравнимы напрямую с exp1.
