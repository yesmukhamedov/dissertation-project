# H-5 — Explainability: Grad-CAM ALO/IoU (Exp 4) → PC-7

**Формулировка.** Grad-CAM моделей с препроцессингом даёт **значимо** больше Attention–Lesion
Overlap (ALO, первичная) и IoU (вторичная) с пиксельными масками поражений IDRiD, чем baseline.

**Реальный исход (прогон 2026-08-02, n = 54 изображения с масками).** `h5_alo_supported = true`.

ALO выше у препроцессированной модели по **всем 4 из 4** типов поражений (критерий ≥3/4), и по
**всем четырём** разница статистически значима:

| Тип | n | ALO (baseline) → ALO (preproc) | Δ | 95% CI (Δ) | p (Wilcoxon, 1-стор.) |
|---|--:|---|---:|---|---:|
| Microaneurysms | 54 | 0.2140 → 0.3180 | +0.1040 | [+0.0412, +0.1668] | 0.0031 |
| Haemorrhages | 53 | 0.2870 → 0.4020 | +0.1150 | [+0.0523, +0.1777] | 0.0018 |
| Hard exudates | 54 | 0.3510 → 0.4830 | +0.1320 | [+0.0684, +0.1956] | 0.0007 |
| Soft exudates | 26 | 0.2260 → 0.3340 | +0.1080 | [+0.0296, +0.1864] | 0.0142 |

Вторичная метрика IoU даёт тот же результат по всем четырём типам (Δ +0.0610…+0.0870,
p = 0.0011…0.0187). Относительный прирост: ALO +37…49%, IoU +45…56%.

**Устойчивость к порогу бинаризации.** Направление сохраняется при **всех** τ ∈ {0.2, 0.3, 0.5, 0.7}
(4/4); значимость теряется лишь у одного типа при самом строгом τ = 0.7 (3/4). Результат не
является артефактом выбора τ = 0.5.

**Эффект пола устранён.** ALO = 0 в обеих арках наблюдается только у **6 из 54** изображений
(f₀ = 0.1111). Измерение ведётся в рабочем диапазоне метрики, а не у границы чувствительности.

**Эффект держится на отдельных наблюдениях, а не на выбросах.** По изображениям: улучшение у
65–74% (MA 38↑/9↓/7=, HE 37/9/7, EX 40/8/6, SE 17/5/4), ухудшение у 15–19%. Средние сдвиги —
результат согласованного смещения большинства.

**Согласованность с классификацией.** Те же две арки EfficientNet-B4 различаются и по
классификации: full wF1 0.7766 против baseline 0.7545 (+2.2пп, +0.024 AUC, +0.047 κ). Прирост
идёт **одновременно** по дискриминативному и локализационному каналу — интерпретация
непротиворечива: конвейер и лучше классифицирует, и лучше выравнивает внимание.

**Обязательная граница — INVARIANTS NC-14.** Grad-CAM активация **не является** клинической
локализацией патологии. Корректная формулировка для §4.5/§5.1: «внимание модели с препроцессингом
значимо лучше выровнено с размеченными поражениями (4/4 типов, p ≤ 0.0142; IoU то же)», а **не**
«модель находит поражения» и не «модель клинически интерпретируема». Подтверждение H-5 не
ослабляет NC-14 — оно измеряет выровненность, а не диагностическую локализацию.

**Оговорки.**
- Одна модель на арку (**fold 0**), кросс-валидации по этому анализу нет.
- Маски доступны только для сегментационного подмножества IDRiD (54 изображения); soft exudates
  размечены на 26 из них — отсюда наибольшее p именно у SE.
- **Клинические (KZ) качественные Grad-CAM overlay не сделаны** — формулировка H-5 их требует.
  Пробел **G-3**, единственный незакрытый по этой гипотезе (см. `HYPOTHESIS_COVERAGE.md`).

(дискриминативный канал), [[H-3]] (механизм сближения доменов), [[exp7-and-SSL]].
