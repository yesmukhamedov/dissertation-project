# H-5 — Explainability: Grad-CAM ALO/IoU (Exp 4) → PC-7

**Формулировка.** Grad-CAM моделей с препроцессингом даёт **значимо** больше Attention–Lesion
Overlap (ALO, первичная) и IoU (вторичная) с пиксельными масками поражений IDRiD, чем baseline
(ALO_preproc > ALO_baseline). EfficientNet-B4.

**Реальный исход (пересчёт 2026-07-28, n = 54): `h5_alo_supported = false`.**
ALO выше у препроцессированной модели лишь для **2 из 4** типов поражений (критерий ≥3/4), **ни по
одному типу разница не значима** (Wilcoxon 1-стор. p ≥ 0.38; все 95% CI включают ноль):

| Тип | n | Baseline → Preprocessed | Δ | p |
|---|---|---|---|---|
| Microaneurysms | 54 | 0.00693 → 0.00786 | +0.0009 | 0.664 |
| Haemorrhages | 53 | 0.00413 → 0.00335 | −0.0008 | 0.660 |
| Hard exudates | 54 | 0.00391 → 0.01126 | +0.0073 | 0.383 |
| Soft exudates | 26 | 0.02422 → 0.00121 | −0.0230 | 0.764 |

Проверка по порогу бинаризации: критерий ≥3/4 выполняется только при пороге 0.2 (при 0.3/0.5/0.7 —
2/4, 2/4, 1/4), значимости нет **ни при каком** пороге. Отрицательный результат порогом не объясняется.

**Почему изменился вердикт (было `true`).** Прежний прогон брал 50 изображений из IDRiD
«B. Disease Grading» (413 шт.), а маски лежат в «A. Segmentation» (54 шт.) → пересечение = **5**
изображений. Новый прогон анализирует **все 54** изображения с масками и **побитово воспроизводит**
старые значения на тех же пяти. Из тех 5: два дали ALO = 0 везде, два (IDRiD_034, IDRiD_042) стали
**хуже** с препроцессингом, и всё «улучшение 3/4 типов» держалось на одном снимке — **IDRiD_017**.
То есть прежний положительный вердикт — артефакт выборки, а не эффект.

**Дополнительное ограничение измерения (эффект пола).** При каноническом пороге 0.5 у **37 из 54**
изображений ALO = 0 по всем типам в обеих арках: область активации Grad-CAM не пересекается с
мелкими поражениями вообще. ALO/IoU здесь работают на границе чувствительности — это ограничение
метрики, а не только объёма данных.

**Что остаётся правдой.** Классификация двух арок B4 на EyePACS по-прежнему в пользу конвейера:
full wF1 0.7766 vs baseline 0.7545 (+2.2пп, +0.024 AUC) — см. `tables/exp4_classification.md`.
То есть конвейер улучшает **классификацию**, но не выравнивает **внимание** по поражениям.

**Для тезиса.** PC-7 переклассифицировать из CONDITIONAL в **NOT SUPPORTED** (направленно 2/4,
статистически 0/4). Формулировка для §4.5/§5.1: «на полном наборе IDRiD-масок препроцессированная
модель не показывает значимо большего перекрытия внимания с поражениями; направленное преимущество
наблюдается лишь у 2 из 4 типов и неустойчиво к порогу». Это **согласуется** со сквозным механизмом
работы: конвейер улучшает дискриминацию/ранжирование ([[H-1]]) и малодатное обучение (exp7), но не
даёт клинически-интерпретируемой локализации (INVARIANTS **NC-14** — Grad-CAM активация в принципе
не является клинической локализацией патологии).

**Следствие для нарратива:** H-5 больше **не** «единственная подтверждённая гипотеза» — после
пересчёта подтверждённых гипотез из H-1/H-2/H-4/H-5/H-6/H-7 не остаётся ни одной полностью;
единственный чистый позитив работы — **exp7** (малые клинические данные, +0.09 F1) и статистически
подтверждённый прирост AUC в exp1 (DeLong p<10⁻⁴). См. `findings/summary-and-dominance.md`.
