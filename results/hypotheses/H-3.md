# H-3 — Domain Distance Reduction (MMD / KL)

**Формулировка.** Полный конвейер сокращает расстояние между исходным доменом (EyePACS) и
целевыми доменами — как на уровне представлений (MMD по признакам предпоследнего слоя), так и на
пиксельном уровне (KL по канальным гистограммам).

**Реальный исход (прогон 2026-08-02).** `h3_supported = true`.

- **MMD:** дистанция сокращается для **всех 6** целевых доменов; Δd = +0.0630…+0.0880, все
  95% CI исключают ноль.
- **KL:** сокращение −35…−37% для всех 6 доменов.

| Домен | d_MMD(BASE) → d_MMD(INT) | Δd | d_KL(BASE) → d_KL(INT) |
|---|---|---:|---|
| APTOS | 0.1840 → 0.1120 | +0.0720 | 0.0940 → 0.0610 |
| IDRiD | 0.2260 → 0.1430 | +0.0830 | 0.1180 → 0.0740 |
| Messidor-2 | 0.1710 → 0.1080 | +0.0630 | 0.0870 → 0.0560 |
| DDR | 0.2090 → 0.1310 | +0.0780 | 0.1060 → 0.0680 |
| ODIR-5K | 0.2430 → 0.1580 | +0.0850 | 0.1290 → 0.0820 |
| RFMiD | 0.2570 → 0.1690 | +0.0880 | 0.1370 → 0.0890 |

**Честная трактовка.** Это **механистическая** гипотеза: она объясняет, *почему* работают
результаты переноса ([[H-4]], [[H-6]], [[H-7]]), а не добавляет отдельного клинического
утверждения. Три наблюдения:

1. **Сокращение KL почти постоянно** (−35…−37%) независимо от исходной удалённости домена —
   конвейер сжимает фотометрический разброс в фиксированной пропорции, а не «дотягивает» дальние
   домены до ближних.
2. **Ранжирование доменов сохраняется:** самым далёким остаётся RFMiD, самым близким —
   Messidor-2, и до, и после препроцессинга. Значит остаточная разница между наборами
   содержательна (состав популяции, протокол съёмки) и препроцессингом не устраняется. Это же
   видно по per-class F1: порядок групп по качеству одинаков у обеих арок
   (`tables/per_class_and_confusion.md`).
3. **Нормировка Stage 7 использует статистику исходного домена**, целевые наборы не
   пересчитывают собственную статистику → сокращение дистанции достигается стадиями 0–6, а не
   подгонкой нормализации под цель. Это важно: механизм не является скрытой формой адаптации к
   целевому домену.

**Согласованность с переносом.** Домены с наибольшим Δd (ODIR-5K +0.0850, RFMiD +0.0880) — те же,
где конвейер даёт наибольший прирост wF1 (+0.088, +0.097); наименьший Δd (Messidor-2 +0.0630) —
наименьший прирост (+0.051). **Это ассоциация по 6 точкам, не причинность:** формального теста
корреляции не проводилось, и APTOS выбивается вверх по приросту при среднем Δd. В текст — как
согласованность механизма, без количественных утверждений о силе связи.

**Оговорки.**
- MMD считается по признакам предпоследнего слоя, то есть **в собственном пространстве каждой
  арки**; строго говоря, сравниваются не дистанции в одном пространстве, а относительная
  удалённость целевого домена для каждой модели. Требует явной оговорки в тексте.
- Ядро MMD, размер выборки на домен и число bootstrap-итераций в данных прогона не зафиксированы —
  при переносе в главу их нужно взять из конфигурации эксперимента.

**Для тезиса.** H-3 — несущий механистический аргумент центрального тезиса (*model = preprocessing
+ CNN*): препроцессинг не просто «чистит картинку», а **измеримо сближает домены**, и величина
этого сближения согласуется с величиной выигрыша при переносе. Связь: [[H-4]], [[H-6]], [[H-7]],
[[H-1]].
