## Стратегия (решена с кандидатом)

- **Честный реврейминг.** Почти все гипотезы (H-1, H-4, H-6, H-7) НЕ подтвердились по реальным
  данным. Диссертация строится на том, что данные реально показали: 4-канальный конвейер
  стабильно улучшает **ранжирование/согласие (AUC, κ)** и **малодатные клинические сценарии**
  (exp7), но НЕ даёт F1-доминирования; часть гипотез опровергнута. Это согласуется с
  анти-оверклейм-правилами `thesis/governance/INVARIANTS.md`. Опровержение — тоже результат.
- **Только реальные числа** из `experiments/outputs/`. Числа из демо/защиты НЕ использовать
  (см. INTEGRITY_NOTE.md — они противоречат реальным результатам).
