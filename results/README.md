## Стратегия (после прогона 2026-08-02)

- **Работа строится на подтверждённых гипотезах.** 6 из 7 подтверждены, эффект конвейера
  устойчив по всем сценариям (in-domain, zero-shot, смена устройства, внешняя клиника, малые
  данные), значим после поправки на множественность и не зависит от бэкбона.
- **Сквозной механизм измерен, а не постулирован.** H-3 показывает сокращение дистанции доменов
  (MMD/KL, 6/6 доменов); аблация exp2 раскладывает прирост по стадиям; во всех экспериментах
  повторяется один паттерн (Δκ > ΔwF1, Δmacro-F1 > ΔwF1, ΔSens ≈ +0.10 при растущей Spec).
  См. `findings/summary-and-dominance.md`.
- **Анти-оверклейм не отменяется.** Подтверждение гипотез не снимает границы `INVARIANTS.md`:
  **NC-14** (Grad-CAM ≠ клиническая локализация) остаётся в силе для H-5; пороги H-4/H-6 берут
  обе арки, поэтому «конвейер спасает перенос» утверждать нельзя; H-7 подтверждена лишь частично,
  и это нужно докладывать прямо. Полный список ограничений — в
  `findings/summary-and-dominance.md`, раздел «Что осталось честно ограниченным».
- **Только числа из этой папки** (и из `experiments/outputs/` после синхронизации). Числа из
  демо/защиты не использовать — см. `INTEGRITY_NOTE.md`.
