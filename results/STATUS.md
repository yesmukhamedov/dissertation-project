| L4 | + Stage 4 | 0.7913 | +0.0090 | 0.0058 | ✓ |

| L6 | + Stage 6 | 0.8103 | +0.0095 | 0.0060 | ✓ |
| L7 | + Stage 7 | **0.8193** | +0.0090 | 0.0056 | ✓ |

Кумулятивно L0 → L7: **+0.0655 wF1**. Монотонность держится **в каждом из 5 фолдов**.

**Свипы:** CLAHE — двумерная сетка (clip × threshold) 7×5, внутренний оптимум θ\* = (2.5, 0.03),
held-out +0.0602 (CI [+0.0411, +0.0793]); flat-field σ — унимодальный максимум σ\* = 0.07·D,
R = 0.052, held-out +0.0570 (CI [+0.0381, +0.0759]). Per-class оптимумы различаются:
θ̂(DR1) = (2.5, 0.03), θ̂(DR2) = (2.0, 0.03).

**Итог:** PC-2 подтверждён полностью (обе части свипов, оба оптимума внутренние + held-out).
PC-8 — все 7 вкладов значимы, но **иерархия плоская** (разброс Δⱼ = 0.0010 < σ_fold), ранжировать
стадии нельзя.

**Ключевое следствие — разложение CFC-2.8:** L0 = 0.7538 = Config C, L7 = 0.8193 = Config D при
единой инициализации → весь прирост exp1 воспроизводится препроцессингом отдельно от SSL-init.

**Оговорки:** порядок стадий фиксирован (вклад стадии при уже наложенных предыдущих);
**Stage 3 не изолирована** (L3 = Stage 2 + 3 совместно); сетки свипов — train-фолды, одна оценка
на точку. Детали: `tables/TAB-4.4_exp2_ablation.md`, `TAB-4.5_exp2_image_quality.md`,
`exp2_clahe_sweep.md`, `exp2_flatfield_sigma_sweep.md`.
