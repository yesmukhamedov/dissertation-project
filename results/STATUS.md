## exp2 — аблация + CLAHE-свип (H-2) — COMPLETE* (с оговорками)

Протокол: аблация на **15%-подвыборке EyePACS (n=5268), 3 фолда, ImageNet-init**; CLAHE-свип на IDRiD.

**Индивидуальная аблация (ΔwF1 vs baseline 0.7611):**

| Уровень | wF1 | ΔwF1 |
|---------|-----|------|
| baseline | 0.7611 ± 0.0192 | — |
| + canonical flip | 0.7701 ± 0.0076 | +0.0091 |
| + flat-field | 0.7603 ± 0.0288 | −0.0007 |
| + CLAHE | 0.7532 ± 0.0343 | −0.0078 |
| + augmentation | 0.7435 ± 0.0396 | **−0.0175** |
| full pipeline | 0.7463 ± 0.0136 | −0.0148 |

> **Правка 2026-07-28:** `full` был 0.7197 ± 0.0328 / −0.0414 — артефакт фолда 2, оборванного на
> 2-й эпохе из 20. Фолд дообучен до правила останова (best ep13, ранняя остановка ep18); по-фолдовые
> значения 0.7361 / 0.7410 / 0.7618. Прежнее число недействительно.

**Итог:** стадии препроцессинга по отдельности НЕ улучшают wF1 (только canonical flip +0.9пп), но
**и не ухудшают его значимо** — все |Δ| ≤ 0.018 при std 0.014–0.040, то есть внутри шума; худший по
wF1/κ теперь `+augmentation`, `full` худший только по AUC (0.8010). Ранжированную иерархию стадий
(PC-8) на этом n построить нельзя. **Подтверждает CFC-2.8**: выигрыш exp1 идёт от SSL-init, не от
препроцессинга. CLAHE-свип: профиль чувствительности с оптимумом есть (H-2/PC-2 CLAHE-часть ✓).
Flat-field повышает CNR (20→42), но не F1 («качество изображения ≠ качество классификации»).
**Оговорки:** 15%/3-fold (высокая дисперсия, различия незначимы); фолд 2 уровня `full` дообучен
отдельным запуском (то же разбиение, иное состояние ГСЧ); нет уровня +OD-fovea rotation;
**σ-свип не прогнан**; числа не сравнимы с exp1 (100%/5-fold/SSL). Детали: `tables/TAB-4.4_exp2_ablation.md`,
`tables/TAB-4.5_exp2_image_quality.md`, `tables/exp2_clahe_sweep.md`, `findings/exp2.md`.

## exp4 — Grad-CAM explainability (H-5) — COMPLETE, НЕ подтверждена

EfficientNet-B4, baseline vs full, Grad-CAM vs маски поражений IDRiD.
**Пересчитано 2026-07-28 на ВСЕХ 54 изображениях с масками** (было 5 — прежний прогон сэмплировал из
«Disease Grading», а маски лежат в «Segmentation»; пересечение = 5).

**ALO (первичная), baseline→preproc, парно, n=54:** microaneurysms 0.00693→0.00786 (p=0.66) ·
haemorrhages 0.00413→**0.00335** (p=0.66) · hard exudates 0.00391→0.01126 (p=0.38) ·
soft exudates 0.02422→**0.00121** (n=26, p=0.76). Улучшены **2 из 4** типов (критерий ≥3/4),
**значимых нет** (все 95% CI включают ноль). IoU — тот же результат. `h5_alo_supported=false`.

Проверка порога бинаризации: 3/4 типов только при 0.2; при 0.3/0.5/0.7 → 2/4, 2/4, 1/4; значимости
нет ни при каком пороге. Новый прогон побитово воспроизводит старые числа на тех же 5 изображениях —
разница целиком в объёме выборки. Из старых 5: два дали нули, два ухудшились, всё «улучшение»
давал один снимок IDRiD_017.

**Что осталось в пользу конвейера:** классификация арок B4 — full wF1 0.7766 vs baseline 0.7545
(+2.2пп, +0.024 AUC). Т.е. конвейер улучшает классификацию, но НЕ выравнивает внимание по поражениям.

**⚠️ Оговорки:** эффект пола — при пороге 0.5 у 37/54 изображений ALO=0 в обеих арках; одна фолд-0
модель на арку; **INVARIANTS NC-14** (Grad-CAM ≠ клиническая локализация). Клинические (KZ) overlay
по H-5 не сделаны — в коде exp4 нет ветки clinical. Детали: `tables/TAB-4.7_exp4_alo_iou.md`,
`tables/exp4_classification.md`, `hypotheses/H-5.md`, `findings/exp4.md`.
